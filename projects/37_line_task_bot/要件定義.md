# 要件定義 — Project 37: LINE Bot → タスク管理連携

## 概要
LINEで送ったメッセージをGemini AIが解析してタスクとして自動登録し、期限1日前に
LINEでリマインダーを送るタスク管理Bot。Webダッシュボードでステータス管理もできる。

## 機能要件
1. LINEでメッセージを送るとWebhookでFlaskが受信する（署名検証あり）
2. 「一覧」と送るとそのユーザーの未完了タスク一覧を返信する
3. それ以外のメッセージはGemini APIがタスク名・期限・カテゴリを抽出し、SQLiteへ保存、
   登録内容を返信する
4. 毎朝9時（JST）にAPSchedulerが、期限が翌日のタスクへLINEでリマインダーを送る
   （送信済みタスクには`reminder_sent`フラグを立てて二重送信を防ぐ）
5. Webダッシュボードでタスク一覧（タスク名・期限・カテゴリ・ステータス）を表示し、
   「完了にする」ボタンでステータスを更新できる

## Webhookの署名検証
LINE Messaging APIのWebhookは`X-Line-Signature`ヘッダー（チャネルシークレットによる
HMAC-SHA256署名）の検証が必須。`line-bot-sdk`の`WebhookHandler`がこれを行い、
署名が不正な場合は400を返す。実機ではLINEの公開HTTPS Webhook URLが必要なため、
ローカルでは正しい署名を計算したテストリクエストで動作確認した。

## データ構造（SQLite + SQLAlchemy）

| カラム（Taskモデル） | 型 | 説明 |
|---|---|---|
| id | Integer PK | 自動採番 |
| line_user_id | String | LINEのユーザーID |
| task_name | String | タスク名 |
| due_date | String (YYYY-MM-DD) | 期限（未設定はNULL） |
| category | String | 仕事／プライベート／買い物／勉強／その他 |
| status | String | 未完了／完了 |
| reminder_sent | Boolean | リマインダー送信済みフラグ |
| created_at | DateTime | 作成日時（UTC） |

## 画面構成・API
- `/`（GET） — Webダッシュボード（タスク一覧・完了ボタン）
- `/webhook`（POST） — LINE Webhook受信エンドポイント
- `/tasks/<id>/complete`（POST） — タスクを完了にする
- `/api/run-reminders`（POST） — リマインダー送信を即時実行する（動作確認用）

## 技術スタック
Flask / line-bot-sdk（v3 API） / APScheduler（毎朝9:00 JST） / SQLite + SQLAlchemy /
Gemini API（`shared.utils.call_claude_json`経由） / Render

## 成功条件
- 不正な署名のWebhookリクエストは400で拒否される
- 正しい署名のメッセージはタスクとして登録され、登録内容がLINEへ返信される
- 「一覧」送信時は未完了タスクの一覧が返信される
- 期限が翌日のタスクにリマインダーが送られ、二重送信されない
- ダッシュボードでタスクのステータスが「完了」に更新できる

## 実機確認について
LINEのWebhookは公開HTTPS URLが必須（localhostでは登録できない）。実際のLINEアプリ
からのメッセージ送受信は、Render等への本番デプロイ後にLINE Developersコンソールで
Webhook URLを設定してから確認する必要がある（ユーザーが既にチャネルを作成済み）。
