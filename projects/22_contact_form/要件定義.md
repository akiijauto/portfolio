# 要件定義 — Project 22: お問い合わせフォーム

## 目的
ポートフォリオ(portal.html)の各種CTA・連絡先リンクを、メールクライアント起動(mailto)依存から
自前のWebフォームに置き換える。送信内容はDiscord Webhookに通知し、既存の連絡フローと統合する。

## 画面構成
1ページのみ。

- お名前（必須・50文字以内）
- 会社名・屋号（任意・100文字以内）
- メールアドレス（必須・100文字以内・形式チェック）
- ご相談のツール（任意・複数選択可のチェックボックス一覧。プロジェクト一覧 + 「その他・全体について」）
- ご相談内容（必須・1000文字以内・文字数カウンタ表示）

URLクエリパラメータ `?tool=...` でツール選択を事前指定できる
（portal.htmlの各PickupカードCTAから `?tool=18 補助金マッチング＆事業計画ドラフト生成` のように遷移すると該当チェックボックスがオンになる）。

## API
### POST /api/submit
- リクエスト: JSON `{name, company, email, tools: [...], message}`
- バリデーション: 必須項目・文字数・メール形式・toolsが配列かつ各要素が選択肢に含まれるか
- 成功時: DiscordにEmbed形式で通知し `{"ok": true}` を返す
- 失敗時: `{"ok": false, "error": "..."}` をエラーメッセージ辞書(`_shared/errors.py`)から返す

## 技術構成
- Flask（Flask-WTF CSRF）
- Discord Webhook（既存の `DISCORD_WEBHOOK_URL` を再利用）
- Vercel（@vercel/python によるサーバーレス関数。`shared/csrf_setup.py`・`shared/errors.py` は
  単独デプロイ用に `_shared/` へ複製）

## 成功条件
- フォーム送信後、Discordチャンネルに問い合わせ内容（お名前・会社名・メールアドレス・ツール（複数可）・相談内容）が通知される
- 入力エラー時は適切な日本語エラーメッセージが表示される
- portal.htmlの主要CTAがこのフォームへのリンクに置き換わっている

## デプロイ
- Vercelに公開し、https://contact-form-gamma-tan.vercel.app で稼働
- portal.htmlの全リンク（ヘッダーお問い合わせボタン、Pickup各CTA、プロジェクト一覧カード、フッター）を
  この本番URLに置き換え、スマートフォンなどローカル環境外からも利用可能にした
- 旧Render環境（contact-form, srv-d8o1ta0g4nts73c6n0d0）はVercel移行に伴い削除済み
