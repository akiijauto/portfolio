# 振り返り — Project 22: お問い合わせフォーム

## 発生した課題と解決策

### 1. mailtoリンクからの移行方法
**課題:** portal.htmlのCTAは`mailto:`リンクで、件名のみプロジェクトごとに変えていたが、
本文を含めた情報（会社名・相談内容など）を入力させることができず、返信時の手間が大きい。

**解決策:** 軽量なFlaskフォームを新規作成し、入力内容をDiscord Webhook経由で通知する形にした。
既存プロジェクトで使っている`DISCORD_WEBHOOK_URL`をそのまま再利用できるため、新たな外部サービス
契約は不要。

### 2. CTAごとに「ご相談のツール」を事前選択させる
**課題:** portal.htmlの各Pickup Projectsカードから問い合わせる際、どのツールについての相談かを
毎回プルダウンで選び直すのは手間。

**解決策:** `/?tool=...` のクエリパラメータでプルダウンの初期選択値を指定できるようにし、
`render_template`側で`selected_tool`と一致する`<option>`に`selected`属性を付与する形にした。
portal.html側ではCTAのhrefに`?tool=`+エンコードしたツール名を付与するだけで連携できる。

### 3. Discord通知の構造化
**課題:** 単純なテキストメッセージでは、お名前・会社名・メール・ツール・相談内容が読みにくい。

**解決策:** Discord WebhookのEmbed機能を使い、フィールドごとに分けて表示する形式にした。
`requests.post(webhook_url, json={"embeds": [embed]})`で送信し、ステータス200/204を成功判定とした。

### 4. 「ご相談のツール」をプルダウンからチェックボックス複数選択に変更
**課題:** プロジェクト数が増えるにつれ、複数のツールについて同時に相談したいケースが想定されるが、
プルダウン（単一選択）では1つしか選べなかった。

**解決策:** `<select>`をチェックボックスのグリッドに置き換え、フロントでは`tools`配列として収集、
バックエンドも`tool`単一文字列から`tools`配列（各要素がTOOLS定義に含まれるかをバリデーション）に変更した。
Discord Embedの「ご相談のツール」フィールドは選択された全ツールを改行区切りで表示する。
`?tool=...`によるCTAからの事前選択も、該当チェックボックスに`checked`を付与する形でそのまま流用できた。
あわせてTOOLS一覧にProject23〜27（最新の店舗運営支援・新規ツール群）を追加した。

### 5. portal.htmlのCTAがlocalhostのみでスマホから使えない
**課題:** portal.htmlの各CTA・連絡先リンクが`http://127.0.0.1:5022`を指していたため、
開発者のローカル環境以外（特にスマートフォン）からはお問い合わせフォームに到達できなかった。

**解決策:** 本プロジェクトをRenderの無料プランに新規デプロイし、
https://contact-form-qxqb.onrender.com として公開。portal.html / portal/index.html内の
`http://127.0.0.1:5022`への参照（ヘッダーボタン・Pickup各CTA・プロジェクト一覧カード・フッター、計7箇所）を
すべて本番URLに置き換えた。プロジェクト一覧カードの表記も「🖥 ローカル稼働」→「🌐 本番稼働中」、
リンクラベルを「▶ localhost:5022」→「🌐 Render」に変更し、他のRenderデプロイ済みプロジェクトの表記と統一した。

### 6. RenderからVercelへの移行
**課題:** Renderの無料プランはビルド時間枠（pipeline minutes）の上限により、デプロイ直後に
`build_failed`となり本番反映が遅延することがあった（Project03/22で発生）。また、Vercelは
すでにportal用に運用されており、デプロイ基盤を統一したいという要望があった。

**解決策:** Flaskアプリをサーバーレス関数として動かすため、`api/index.py`（`app.py`を読み込むだけの
エントリーポイント）と`vercel.json`（`@vercel/python`、`includeFiles`でapp.py・_shared・templates・
staticを含める設定）を追加。`shared/csrf_setup.py`・`shared/errors.py`は単独デプロイのため
`_shared/`へ複製し、`app.py`の`sys.path`操作を廃止してテンプレート/静的フォルダを絶対パス指定に変更。
Vercel CLI（`npx vercel link` → `vercel env add`でDISCORD_WEBHOOK_URL/SECRET_KEYを設定 →
`vercel --prod`）でデプロイし、https://contact-form-gamma-tan.vercel.app で稼働確認。
portal.html / portal/index.htmlの全7リンクをこのURLに置き換え、`🌐 Render`ボタンも
`🌐 Vercel`（黒背景の`.btn-vercel`クラスを新設）に変更。旧Renderサービスは
RENDER_API_KEYで削除し、render.yamlからも定義を除去した。
