# 要件定義 — Project 19: 接客・クレーム対応ロールプレイAI

## 概要

PROJECT 18に続く「店舗運営・教育支援（バックエンド領域）」の第2弾。
新人・アルバイトスタッフが、AIが演じる「客」との対話を通じて、クレーム対応・理不尽な要求・言語の壁といった
現場で起こりがちな接客シーンを安全に練習できるロールプレイ訓練ツール。
ロールプレイ終了後はClaudeが対応内容を5項目で採点し、良かった点・改善点・より良い対応例をフィードバックする。
「対話シミュレーション → AIによる多軸評価」という、生成AIの対話能力と評価能力を両方活用する構成が特徴。

## 機能要件

### ① シナリオ選択
- 5種類のシチュエーションから1つを選択
  - 料理に異物が入っていたというクレーム（飲食店）
  - 常連だからと理不尽な割引・特別対応を要求（店舗共通）
  - 言葉が伝わりにくい外国人観光客への対応（飲食店・宿泊）
  - 予約時間より長時間待たされたことへの不満（飲食店・サロン）
  - 購入した商品が不良品だったという返品・交換要求（小売店）
- 難易度（ふつう／難しい）を選択
- 「ロールプレイを開始する」でAI客の最初の発言を生成し②へ

### ② ロールプレイ
- AI客とのチャット形式の対話画面
- スタッフ役として返答（500文字以内）を入力 → AI客が応答を生成
- ターン数を表示（最大8ターン）、上限到達で入力を無効化
- 「ロールプレイを終了して採点する」でいつでも③へ遷移可能

### ③ 採点結果
- これまでの対話ログをClaudeが評価し、以下を返す
  - 5項目（傾聴・共感／謝罪・誠意／説明の分かりやすさ／提案・解決力／言葉遣い・態度）を0〜5点で採点
  - 総合点（5項目合計／25点）と総合コメント
  - 良かった点・改善点（各2〜3個）
  - より良い対応の例（モデルアンサー）
- 「別のシナリオで再挑戦する」で①へリセット

## データ・API連携

### アプリ内API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/api/start` | POST | シナリオ・難易度を指定し、AI客の最初の発言を生成（`scenario`, `difficulty`） |
| `/api/reply` | POST | スタッフの発言とこれまでの会話履歴を送り、AI客の次の発言を生成（`scenario`, `difficulty`, `staff_message`, `history`） |
| `/api/score` | POST | 会話履歴全体を採点（`scenario`, `difficulty`, `history`） |

## 画面構成（タブ）

1. **①シナリオ選択** — シチュエーションカード一覧＋難易度選択 → ロールプレイ開始
2. **②ロールプレイ** — AI客とのチャット画面、ターン数表示、終了・採点ボタン
3. **③採点結果** — 総合点・5項目スコアバー・総合コメント・良かった点／改善点・より良い対応例

## 技術スタック

- Flask + Flask-WTF（CSRF）
- Anthropic Claude API（claude-haiku-4-5） — AI客の応答生成・対話採点
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `shared/utils.py`（`call_claude_json`）, `static/base.css`

## 成功条件

1. シナリオと難易度を選択して開始すると、AI客の最初の発言が表示される
2. スタッフとして返答を入力すると、AI客が会話の流れに応じた応答を返し、最大8ターンまで対話できる
3. 「採点する」を実行すると、5項目のスコア・総合コメント・良かった点／改善点・より良い対応例が表示される
4. ローカル起動 `python app.py` → ポート 5019 で動作（永続化データは持たないステートレスツール）
