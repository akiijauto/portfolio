# 接客・クレーム対応ロールプレイAI

新人・アルバイトスタッフ向けの接客訓練ツールです。AIが演じる「客」とのチャット形式のロールプレイで、
クレーム対応や理不尽な要求などの難しい接客シーンを安全に練習し、終了後にClaude AIが対応を採点・フィードバックします。

## できること

1. **シナリオ選択** — 5種類の接客シチュエーション（クレーム・理不尽な要求・外国人対応・待ち時間トラブル・返品要求）と難易度（ふつう／難しい）を選択
2. **ロールプレイ** — AI客とチャット形式で対話。スタッフ役として返答を入力すると、AI客が会話の流れに応じて反応（最大8ターン）
3. **採点結果** — 「傾聴・共感」「謝罪・誠意」「説明の分かりやすさ」「提案・解決力」「言葉遣い・態度」の5項目（各0〜5点）で採点し、良かった点・改善点・より良い対応例をフィードバック

## 使い方

1. 「①シナリオ選択」タブでシチュエーションと難易度を選び、「ロールプレイを開始する」
2. 「②ロールプレイ」タブでAI客とのチャットに対応（スタッフとしての返答を入力して送信）
3. 対話が一区切りついたら「ロールプレイを終了して採点する」で「③採点結果」タブへ
4. 結果を確認後、「別のシナリオで再挑戦する」で別のシナリオに挑戦可能

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に以下を設定
#   ANTHROPIC_API_KEY

# このプロジェクトディレクトリで起動
cd projects/19_roleplay_training
python app.py
```

ブラウザで http://127.0.0.1:5019 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask（Flask-WTF CSRF） |
| AI生成 | Anthropic Claude API（claude-haiku-4-5） — AI客の応答生成・対話採点 |

## 注意事項

- スタッフの発言は500文字以内、ロールプレイは最大8ターンまでです
- AIによる採点・フィードバックは練習用の参考情報です
- データの永続化は行わないステートレスなツールです
