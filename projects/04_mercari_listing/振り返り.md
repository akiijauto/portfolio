# 04_mercari_listing 振り返り

## 開発中に発生した課題と解決策

### Claude APIのレスポンスをJSONとして受け取る
- **課題**: Claudeのレスポンスが文字列で返るため、価格などの数値項目をパースする必要があった
- **解決**: `call_claude_json()` にJSONスキーマを明示したプロンプトを渡し、structuredな出力を強制した

### 状態テンプレートの言語ゆれ
- **課題**: 「新品同様」「未使用」など表現が曖昧で生成文の品質が安定しなかった
- **解決**: ドロップダウンの選択肢を「新品 / ほぼ新品 / やや傷あり / 傷・汚れあり / 全体的に状態が悪い」に統一し、プロンプトにそのまま渡すことで安定化
