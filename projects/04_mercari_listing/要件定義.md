# 04_mercari_listing 要件定義

## 概要
メルカリ出品文をAIで自動生成するWebアプリ。商品名・状態・カテゴリを入力するとタイトル・説明文・価格帯・出品のコツをJSON形式で返す。

## 機能要件
- 商品名・状態（新品〜状態が悪い）・カテゴリをフォームで入力
- Claude Haiku APIで出品文を生成
- 生成結果：タイトル・説明文・最低価格・最高価格・カテゴリ・出品コツ

## データ構造
```json
{
  "title": "商品タイトル",
  "description": "出品説明文",
  "price_min": 1000,
  "price_max": 1500,
  "category": "カテゴリ名",
  "tips": ["コツ1", "コツ2"]
}
```

## 画面構成
- `/` — 入力フォーム（商品名・状態ドロップダウン・カテゴリ）
- 送信後：生成結果を同ページに表示

## 技術スタック
| 要素 | 内容 |
|------|------|
| フレームワーク | Flask |
| AI | Anthropic Claude Haiku (`call_claude_json`) |
| ポート | 5004 |

## 環境変数
| 変数名 | 用途 |
|--------|------|
| `ANTHROPIC_API_KEY` | Claude API認証 |
| `SECRET_KEY` | Flaskセッション（省略可） |

## 成功条件
- 商品名・状態を入力してフォーム送信するとJSON形式の出品文が表示される
- 価格帯・カテゴリ・コツが含まれている
