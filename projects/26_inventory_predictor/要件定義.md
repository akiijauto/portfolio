# 要件定義 — Project 26: 在庫発注タイミング予測AI

## 背景・目的
店舗の在庫管理では、発注のタイミングが遅れると欠品、早すぎると過剰在庫・保管コスト増につながる。
商品ごとの現在の在庫数・1日あたりの平均消費量・発注リードタイムを入力するだけで、
Claude AIが発注の緊急度・推奨タイミング・推奨発注量を提示し、欠品・余剰在庫を防ぐ判断材料を提供する。

## 主な機能
1. **在庫情報入力**
   - 商品一覧（最大30件）: 商品名・現在の在庫数・1日あたりの平均消費量・発注リードタイム(日)・発注ロット
   - 追加の考慮事項（自由記述、任意、最大1000文字。例: イベントによる需要増の見込み）
   - 「サンプルデータを読み込む」で1クリックでデモデータを入力可能
2. **AIによる発注予測**
   - 商品ごとに「在庫が尽きるまでの予測日数」「緊急度（緊急/早めに発注/様子見）」
   - 発注タイミングに関する具体的なアドバイス
   - 推奨発注量
   - 在庫全体で気になる点・改善提案

## 入力・出力仕様
### `POST /api/predict`
- リクエスト: `{ "items": [...], "notes": "..." }`
  - `items[]`: `{ name, current_stock, avg_daily_usage, lead_time_days, order_lot }`（最大30件、数値はすべて0以上）
  - `notes`: 1000文字以内（任意）
- レスポンス: `{ "ok": true, "result": { items[], overall_concerns[], suggestions[] } }`
  - `items[]`: `{ name, days_until_stockout, urgency, reorder_advice, recommended_order_qty, note }`

## 計算ロジック・設計上の注意点
- 基本ロジック: 「在庫が尽きるまでの予測日数 = 現在の在庫 ÷ 1日あたりの平均消費量」を起点に、
  発注リードタイムとの比較から緊急度をAIが判定する。
- 発注ロットが指定されている場合は、推奨発注量をその倍数に近い値で提案する。
- データから判断できない・確認が必要な内容は無理に記載せず、空文字または空配列で返す。
