# 在庫発注タイミング予測AI

商品ごとの在庫数・消費ペース・発注リードタイムを入力すると、Claude AIが発注タイミングの緊急度と
推奨発注量を予測するWebアプリです。

## 使い方
1. 「①在庫情報入力」タブで商品一覧を入力します。
   - 「サンプルデータを読み込む」ボタンで、デモ用のデータを一括入力できます。
2. 「AIで発注タイミングを予測する」を押すと、AIが商品ごとの予測を生成します。
3. 「②発注予測」タブに、商品ごとの緊急度（緊急/早めに発注/様子見）・在庫が尽きるまでの予測日数・
   推奨発注量・アドバイスが表示されます。

## 起動方法
```bash
python app.py
```
`http://127.0.0.1:5026` で起動します。

## 技術構成
- Flask + Flask-WTF（CSRF対策）
- Claude API（claude-haiku-4-5）で発注予測をJSON形式で生成
- フロントエンドはタブ切り替え式の単一ページ（Vanilla JS）
- DBなし・ステートレス構成
