# 業務マニュアル・SOP自動生成

業務名とざっくりした手順メモを入力するだけで、Claude AIが新人教育用の業務マニュアル（SOP）を
自動生成するWebアプリです。

## 使い方
1. 「①入力」タブで業務名・対象者・ざっくりした手順を入力します。
   - 「サンプルを読み込む」ボタンで、デモ用のデータ（レジ締め作業）を一括入力できます。
2. 「AIでマニュアルを作成する」を押すと、AIがマニュアルを生成します。
3. 「②マニュアル」タブに、目的・準備するもの・作業手順・よくあるミスと対策・完了チェックリストが表示されます。
4. 「コピー」「ダウンロード」ボタンで、生成結果をテキストとして取得できます。

## 起動方法
```bash
python app.py
```
`http://127.0.0.1:5025` で起動します。

## 技術構成
- Flask + Flask-WTF（CSRF対策）
- Claude API（claude-haiku-4-5）でマニュアルをJSON形式で生成
- フロントエンドはタブ切り替え式の単一ページ（Vanilla JS）
- DBなし・ステートレス構成（生成結果はブラウザ側のJS変数で保持）
