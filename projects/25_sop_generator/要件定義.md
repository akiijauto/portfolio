# 要件定義 — Project 25: 業務マニュアル・SOP自動生成

## 背景・目的
新人スタッフへの業務引継ぎでは、ベテランの頭の中にある手順を文書化する作業が後回しになりやすい。
業務名と「ざっくりした手順メモ」を入力するだけで、Claude AIが新人が読んでそのまま作業できるレベルの
業務マニュアル（SOP: Standard Operating Procedure）を生成し、文書化のハードルを下げる。

## 主な機能
1. **入力**
   - 業務名（例: レジ締め作業）
   - 対象者（例: 新人スタッフ・アルバイト）
   - ざっくりした手順・メモ（自由記述、最大2000文字）
   - その他の補足（任意、最大1000文字）
   - 「サンプルを読み込む」で1クリックでデモ入力可能
2. **AIによるマニュアル生成**
   - タイトル・目的
   - 準備するもの（チェックリスト形式）
   - 作業手順（ステップごとにタイトル・説明・コツ/注意点）
   - よくあるミスと対策
   - 完了チェックリスト（チェックボックス付き）
   - コピー・テキストダウンロード対応

## 入力・出力仕様
### `POST /api/generate`
- リクエスト: `{ "task_name": "...", "target_audience": "...", "rough_steps": "...", "notes": "..." }`
  - `task_name`: 100文字以内
  - `target_audience`: 100文字以内
  - `rough_steps`: 2000文字以内
  - `notes`: 1000文字以内（任意）
- レスポンス: `{ "ok": true, "result": { title, purpose, preparation[], steps[], common_mistakes[], checklist[] } }`
  - `steps[]`: `{ step_no, title, description, tips }`

## 設計上の注意点
- 入力情報から読み取れない内容（特にcommon_mistakes）は無理に創作せず空配列で返す。
- ステップ数は5〜10程度に整理し、新人が迷わない粒度にする。
- 生成結果はDBに保存せず、ブラウザ側で保持（ステートレス構成）。
