# 要件定義 — Project 31: 画像→テキスト OCR変換ツール

## 概要
写真・スキャン画像・PDFをアップロードすると文字起こしを行い、Gemini AIで誤字補正・
文章整形して出力するWebアプリ。

## 機能要件
1. 画像ファイル（JPG/PNG）またはPDFをアップロードする（20MBまで）
2. OpenCVで画像前処理（グレースケール化・ヒストグラム均等化・二値化）を行う
3. pytesseract（Tesseract OCR）で日本語＋英語のOCRを実行する
4. （オプション）Gemini APIでOCR結果の誤字補正・文章整形を行う
5. 整形済みテキストをワンクリックでコピーできる
6. 整形済みテキストをTXTファイルとしてダウンロードできる
7. 複数ページのPDFは全ページを一括OCRし、ページ区切りを付けて連結する

## システム依存（pipパッケージでは解決しない部分）
- **Tesseract OCR本体**（pip経由ではなくOS側のインストールが必要）
  - ローカル（Windows）: winget等でインストール。日本語データ`jpn.traineddata`は
    別途 https://github.com/tesseract-ocr/tessdata から取得し、本アプリでは
    `projects/31_ocr_tool/tessdata/`に配置して`TESSDATA_PREFIX`で参照する
    （Program Filesへの書き込み権限が無い環境でも動くようにするため）
  - Render（本番）: `render.yaml`のbuildCommandで`apt-get install tesseract-ocr tesseract-ocr-jpn`
- **Poppler**（PDF→画像変換、pdf2imageが内部で利用）
  - ローカル（Windows）: winget等でインストール
  - Render（本番）: `render.yaml`のbuildCommandで`apt-get install poppler-utils`

## データ構造
DBは使用しない。アップロードされた画像・PDFはメモリ上で処理し、ディスクに保存しない。

## 画面構成
- `/` — アップロードフォーム・結果表示（テキストエリア・コピー・ダウンロード）
- `/ocr`（POST） — OCR実行
- `/download`（POST） — TXTダウンロード

## 技術スタック
Flask / pytesseract + Tesseract OCR / OpenCV (opencv-python-headless) / pdf2image + Poppler /
Gemini API（`shared.utils.call_claude_text`経由） / Render

## 成功条件
- JPG/PNG/PDF以外の拡張子はアップロード時に拒否される
- 日本語混在の画像でも文字起こしができる（OCR単体での完全な精度は保証しないが、
  AI補正により実用的な文章になる）
- 複数ページPDFが正しくページ単位で連結表示される
- Gemini APIキー未設定・AI補正失敗時もOCR結果がそのまま表示され、処理が落ちない
