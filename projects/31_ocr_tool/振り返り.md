# 振り返り — Project 31: 画像→テキスト OCR変換ツール

## 発生した課題と解決策

### 1. Tesseract OCR本体はpipでは入らない
`pytesseract`はTesseract本体を呼び出すだけのラッパーで、OCRエンジン自体は
別途OSにインストールする必要があった。Windowsでは`winget install UB-Mannheim.TesseractOCR`、
PDF処理に使う`pdf2image`が依存するPopplerも`winget install oschwartz10612.Poppler`で
別途インストールした。Render本番では`render.yaml`のbuildCommandに
`apt-get install tesseract-ocr tesseract-ocr-jpn poppler-utils`を追記することで対応する
（要件定義書の備考通り）。

### 2. 日本語OCRデータが標準インストールに含まれない
Tesseractの標準インストーラーには英語（`eng.traineddata`）のみが入り、日本語
（`jpn.traineddata`、約35MB）は別途ダウンロードが必要だった。さらに、Tesseractの
インストール先（`C:\Program Files\Tesseract-OCR\tessdata\`）への書き込みには管理者権限が
必要で、通常ユーザー権限ではコピーできなかった。そこで、プロジェクト内に
`tessdata/`フォルダを用意し、起動時に`TESSDATA_PREFIX`環境変数でそのフォルダを
指すよう設定することで、管理者権限なしに日本語OCRを動かせるようにした。
このフォルダは大容量バイナリのため`.gitignore`に追加し、READMEに取得手順を記載した。

### 3. OCR単体の精度限界とAI補正の役割分担
Tesseractは綺麗な印刷物でもまれに誤字（例: 「こんにちは」→「ご こ ん に ち は」のような
分かち書きや誤認識）が発生する。OCR側でこれを完全に解決するのは難しいため、
「OCRはとにかく文字を抽出する」「整形・誤字補正はAIに任せる」という役割分担にし、
チェックボックスでAI補正のON/OFFを選べるようにした。
