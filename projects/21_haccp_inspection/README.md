# 写真ベース 衛生点検・HACCP記録サポート

冷蔵庫の温度表示や調理エリアの清掃状況などを撮影した写真をClaude AI（画像認識）が確認し、
HACCP（食品衛生管理）の点検記録として使える判定・コメントを自動生成するツールです。

## できること

1. **点検実施** — 点検カテゴリ（冷蔵・冷凍庫の温度表示／調理台・作業エリアの清掃状況／食材の保管状態／手洗い・消毒設備／ゴミ箱・排水口の管理状況／スタッフの服装・衛生／その他）を選び、写真をアップロード
2. **AI点検** — Claude AIが写真を解析し、観察結果・チェック項目別の判定（OK／要注意／NG／確認不可）・総合判定・問題点・改善アクション・記録用コメントを表示
3. **本日の点検記録** — 実施した点検結果を時系列で一覧表示し、テキストファイルとしてダウンロード

## 使い方

1. 「①点検実施」タブで点検カテゴリを選び、点検対象の写真をアップロード（補足コメントは任意）
2. 「AIで点検する」をクリックすると、AIによる点検結果が表示される
3. 「②本日の点検記録」タブでこれまでの点検結果を確認し、必要に応じてテキストでダウンロード

```
21_haccp_inspection/
├── app.py          … Flaskアプリ本体（ルーティング・画像アップロード処理）

    ├── app.js       … 画像プレビュー・点検実行・記録一覧
```

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に以下を設定
#   ANTHROPIC_API_KEY

# このプロジェクトディレクトリで起動
cd projects/21_haccp_inspection
python app.py
```

ブラウザで http://127.0.0.1:5021 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask（Flask-WTF CSRF） |
| AI生成 | Anthropic Claude API（claude-haiku-4-5、画像入力対応） — 写真の解析・点検判定・記録コメント生成 |

## 注意事項

- 写真はJPEG・PNG・WebP形式、5MB以内に制限されています
- 補足コメントは300文字以内です
- 写真から判断できない項目は「確認不可」として表示されます。AIによる点検結果は補助情報であり、最終的な判断は店舗側で行ってください
- 点検記録はブラウザのセッション内のみ保持され、データの永続化は行いません
