# 要件定義 — Project 21: 写真ベース 衛生点検・HACCP記録サポート

## 概要

PROJECT 18〜20に続く「店舗運営・教育支援（バックエンド領域）」の第4弾。
冷蔵庫の温度表示・調理エリアの清掃状況・食材保管状態などを撮影した写真をClaude AIの画像認識で
確認し、HACCP（食品衛生管理）の点検記録として使える判定・コメントを自動生成するツール。
「写真アップロード → AI画像解析 → 点検記録の構造化」という、生成AIの画像理解を活用した
店舗衛生管理の補助という点が特徴。

## 機能要件

### ① 点検実施
- 点検カテゴリを選択（必須）
  - 冷蔵・冷凍庫の温度表示
  - 調理台・作業エリアの清掃状況
  - 食材の保管状態（容器・ラップ・期限表示など）
  - 手洗い・消毒設備
  - ゴミ箱・排水口の管理状況
  - スタッフの服装・衛生（帽子・手袋など）
  - その他
- 点検対象の写真をアップロード（JPEG/PNG/WebP、5MB以内、必須）
  - アップロード後にプレビュー表示
- 補足コメント（任意・300文字以内）を入力
- 「AIで点検する」でClaudeが写真を解析し、以下を表示:
  - 観察結果（写真から確認できる内容の説明）
  - チェック項目ごとの判定（OK／要注意／NG／確認不可）とコメント
  - 総合判定（OK／要注意／NG）
  - 問題点（あれば）
  - 改善アクション（あれば）
  - HACCP記録表に記入できる一言コメント

### ② 本日の点検記録
- ①で実施した点検結果を時系列で一覧表示（時刻・カテゴリ・判定・コメント・写真サムネイル）
- 「記録をテキストでダウンロード」で本日の点検記録一覧をテキストファイルとして出力

## データ・API連携

### アプリ内API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/api/inspect` | POST | 写真点検（multipart/form-data: `image`, `category`, `notes`） |

## 画面構成（タブ）

1. **①点検実施** — カテゴリ選択・写真アップロード・補足コメント → AI点検結果表示
2. **②本日の点検記録** — 点検結果の一覧（時刻・カテゴリ・判定・コメント）・テキストダウンロード

## 技術スタック

- Flask + Flask-WTF（CSRF）
- Anthropic Claude API（claude-haiku-4-5、画像入力対応） — 写真の解析・点検判定・記録コメント生成
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `shared/utils.py`（`extract_json`, `TRANSIENT_ANTHROPIC_ERRORS`）, `static/base.css`

## 成功条件

1. 点検カテゴリと写真をアップロードして「AIで点検する」を実行すると、観察結果・チェック項目別判定・総合判定・問題点・改善アクション・記録用コメントが表示される
2. 写真から判断できない項目は「確認不可」として無理に断定しない
3. 点検結果が「②本日の点検記録」に時系列で蓄積され、テキストファイルとしてダウンロードできる
4. ローカル起動 `python app.py` → ポート 5021 で動作（永続化データは持たないステートレスツール。点検記録はブラウザのセッション内のみ保持）
