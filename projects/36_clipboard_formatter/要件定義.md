# 要件定義 — Project 36: ブラウザ拡張連携 クリップボード自動整形

## 概要
Chrome拡張機能（Manifest V3）でコピーしたテキストをFlask REST APIへ送信し、Gemini AI
で整形（誤字修正・箇条書き変換・要約・丁寧語変換）して結果を返すツール。

## 機能要件
1. Chrome拡張のポップアップでテキストを入力（またはクリップボードから貼り付け）する
2. 整形モード（誤字修正／箇条書き変換／要約／丁寧語変換）をポップアップ上で選択する
3. Flask APIがGemini APIで整形処理を行い、結果をポップアップに返す
4. 整形済みテキストをワンクリックでクリップボードにコピーできる
5. Webダッシュボードで整形履歴（モード・原文・結果・日時）をSQLiteから一覧表示する

## CORS設定
Chrome拡張の拡張ID（`chrome-extension://...`）はインストール環境ごとに異なるため、
`/api/*`配下のエンドポイントはCORSオリジンを`*`許可している。認証なしの整形専用APIで
個人情報を保存しない前提のため、学習用途としてはオープンな設定とした
（本番で不特定多数に公開する場合は、拡張IDをホワイトリスト化するなどの追加対策を検討）。

## データ構造（SQLite, `instance/history.db`）

| カラム | 型 | 説明 |
|---|---|---|
| id | INTEGER PK | 自動採番 |
| mode | TEXT | 整形モード（summarize/bullet/proofread/polite） |
| original_text | TEXT | 整形前のテキスト |
| result_text | TEXT | 整形後のテキスト |
| created_at | TEXT | 作成日時（UTC, ISO8601） |

## 画面構成・API
- `/`（GET） — Webダッシュボード（整形履歴一覧）
- `/api/format`（POST） — `{text, mode}`を受け取り、整形結果`{ok, result}`を返す
- `/api/history`（GET） — 整形履歴をJSONで返す

## Chrome拡張の構成
`extensions/project36/`に格納する。
- `manifest.json`（Manifest V3、`clipboardRead`/`clipboardWrite`権限）
- `popup.html` / `popup.css` / `popup.js`（バックエンドAPIへfetch、結果表示・コピー）

## 技術スタック
Chrome Extension（Manifest V3） / Flask（REST API） / Flask-CORS / SQLite /
Gemini API（`shared.utils.call_claude_text`経由） / Render（バックエンドのみ）

## 成功条件
- テキスト未入力・5000文字超・未対応モード指定時はAPIが400エラーを返す
- AI整形に失敗した場合は502エラーを返し、履歴には保存しない
- 整形成功時は履歴に1件保存され、ダッシュボードに反映される
- Chrome拡張からのCORSリクエストが許可される（実機でAPI単体の動作を確認済み）
