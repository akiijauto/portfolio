# 要件定義 — Project 33: Markdown→スライド自動生成

## 概要
Markdownテキストを入力するだけで、HTMLプレゼンテーション（reveal.js）とPowerPointファイル
（.pptx）の両方を生成できるWebアプリ。

## 機能要件
1. ブラウザのテキストエリアにMarkdownを入力する
2. `---` で区切られたスライドごとに `# 見出し` をタイトル、`- ` 箇条書きを本文として認識する
3. （オプション）Gemini APIで章立て・スライド構成を自動整理する
4. reveal.js（CDN）を使ったHTMLスライドをその場でプレビューできる
5. python-pptxでPPTXファイルを生成・ダウンロードできる
6. テーマカラー（blue/green/orange/purple）を選択できる

## データ構造
DBは使用しない。フォーム入力のMarkdownテキストをそのままプレビュー・PPTX生成に使う。

## 画面構成
- `/` — Markdown入力フォーム（テーマ選択・AI最適化チェックボックス）
- `/preview`（POST） — reveal.jsでスライドプレビューを表示
- `/export/pptx`（POST） — PPTXファイルを生成しダウンロードさせる

## 技術スタック
Flask / python-pptx / reveal.js（CDN） / Gemini API（`shared.utils.call_claude_text`経由） / Render

## 成功条件
- Markdown未入力時はエラーメッセージを表示し再入力を促す
- `---` 区切りで複数スライドが正しく分割・表示される
- PPTXファイルがPowerPoint/Google Slidesで正しく開ける
- AI最適化チェックを入れた場合、Gemini APIキー未設定でもエラーにならず元のテキストでプレビューする
