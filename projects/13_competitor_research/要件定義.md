# 要件定義 — Project 13: 競合調査ツール

## 概要

SEO記事を書く前に、検索上位の競合ページを自動で調査し、コンテンツのギャップ・差別化案・推奨タイトルをClaude AIが提案するツール。
戦略レビューで「SEO記事執筆の前に競合調査を行うべき」と指摘されたことを受け、Phase 3の最優先（Priority 1）として実装。

## 機能要件

### ① キーワード検索
- キーワードを入力すると、Tavily Search API（`TAVILY_API_KEY`未設定時はDuckDuckGo）で検索し上位5件のURLを取得
- 取得したURLを一覧表示し、分析対象をチェックボックスで選択

### ② 競合分析
- 選択したURL（最大5件）を自動スクレイピングし、以下を抽出
  - タイトル / メタディスクリプション / H1〜H3見出し / 本文文字数 / ドメイン
- 抽出結果をもとにClaude AIが分析レポートをMarkdown形式で生成
  - 1. 競合の共通パターン
  - 2. コンテンツギャップ（競合の弱点）
  - 3. 差別化コンテンツ案（2〜3案）
  - 4. 推奨タイトル案（3案）
- レポートはコピー可能

## データ構造・API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/search` | POST | キーワードで検索し上位URLを返す（`keyword`、最大200文字） |
| `/analyze` | POST | 指定URL（最大5件）をスクレイピング＋Claude分析（`keyword`, `urls`改行区切り） |

## 画面構成（タブ）

1. **①キーワード検索** — キーワード入力 → 上位URL一覧 → 分析対象選択
2. **②分析結果** — スクレイピング結果カード + AI分析レポート（Markdownプレビュー）

## 技術スタック

- Flask + Flask-WTF（CSRF）
- BeautifulSoup4（スクレイピング）
- Tavily Search API（メイン）／DuckDuckGo HTML検索（`https://html.duckduckgo.com/html/`、フォールバック）
- Anthropic Claude API（claude-haiku-4-5）
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `static/base.css`

## 成功条件

1. キーワードを入力すると、検索結果から実URL（広告・DDG内部リンクを除く）が5件取得できる
2. 選択したページのタイトル・見出し・文字数が正しくスクレイピングされる（日本語含む）
3. Claude AIが「共通パターン／コンテンツギャップ／差別化案／推奨タイトル」の4セクションを含むレポートを生成する
4. ローカル起動 `python app.py` → ポート 5013 で動作
