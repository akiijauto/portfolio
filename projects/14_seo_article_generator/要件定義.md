# 要件定義 — Project 14: SEO記事生成ツール

## 概要

キーワードを指定するだけで、SEOを意識した記事の「アウトライン」と「本文」をClaude AIが2段階で生成するツール。
Phase 3 Priority 2として、Project 13（競合調査ツール）の分析結果を踏まえた構成案を作るフローを想定して実装。

## 機能要件

### ① キーワード・設定
- キーワード、記事タイプ（解説記事／ハウツー／まとめ記事／事例紹介）、文体（です/ます体・カジュアル・専門的）、目標文字数（500〜5000字）を指定
- Project 13の競合分析結果（テキスト）を任意で貼り付け、アウトライン生成時の参考情報として利用可能

### ② 記事構成（アウトライン生成）
- タイトル（32文字以内）、メタディスクリプション（120文字以内）、導入フック、H2/H3見出し構成（5〜7セクション）、まとめの要点、FAQ（3問）をJSON形式でClaudeが生成
- 生成結果を画面上で確認

### ③ 記事本文
- 確定したアウトラインをもとに、Markdown形式の記事本文をClaudeが一括生成
- Markdownプレビュー / ソース表示の切り替え
- Markdownテキスト・プレーンテキストとしてコピー可能
- 生成結果の文字数を表示

## データ構造・API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/outline` | POST | アウトライン生成（`keyword`, `article_type`, `tone`, `target_chars`, `competitor_context`） |
| `/generate` | POST | 本文生成（`keyword`, `outline`(JSON文字列), `tone`, `target_chars`） |

アウトラインJSON構造:
```json
{
  "title": "...", "meta_desc": "...", "intro_hook": "...",
  "sections": [{"h2": "...", "purpose": "...", "h3s": ["...", "..."]}],
  "conclusion_point": "...",
  "faq": ["...", "...", "..."]
}
```

## 画面構成（タブ）

1. **①キーワード・設定** — キーワード/記事タイプ/文体/目標文字数/競合調査結果の入力
2. **②記事構成** — アウトラインJSONの内容を構造化表示
3. **③記事本文** — Markdown本文（プレビュー/ソース切り替え、コピー機能）

## 技術スタック

- Flask + Flask-WTF（CSRF）
- Anthropic Claude API（claude-haiku-4-5） — アウトライン生成・本文生成の2段階呼び出し
- フロントエンドのMarkdown→HTML変換は独自JS正規表現実装
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `static/base.css`

## 成功条件

1. キーワードを入力すると、5〜7セクションのアウトライン（JSON）が生成される
2. アウトラインから目標文字数に近いMarkdown記事本文が生成される
3. Project 13の分析結果を貼り付けると、それを踏まえたアウトラインになる
4. ローカル起動 `python app.py` → ポート 5014 で動作
