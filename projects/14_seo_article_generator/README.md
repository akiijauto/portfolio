# SEO記事生成ツール

キーワードを入力するだけで、SEO記事の「アウトライン確認 → 本文一括生成」の2ステップで記事が完成するツールです。
Project 13（競合調査ツール）の分析結果を貼り付けると、競合のコンテンツギャップを踏まえた構成を生成できます。

## できること

1. **記事構成の生成** — キーワード・記事タイプ・文体・目標文字数からタイトル/メタディスクリプション/見出し構成/FAQをAIが生成
2. **競合分析の活用** — Project 13で得た分析結果を貼り付けると、それを踏まえたアウトラインになる
3. **記事本文の一括生成** — 確定したアウトラインから目標文字数に沿ったMarkdown記事を生成
4. **Markdownプレビュー** — 生成結果をMarkdownプレビュー/ソース表示で切り替え
5. **コピー機能** — Markdownテキスト・プレーンテキストの両方をコピー可能

## 使い方

1. 「①キーワード・設定」タブでキーワード・記事タイプ・文体・目標文字数を入力（任意で競合調査結果を貼り付け）
2. 「②記事構成」タブでアウトラインを生成・確認
3. 「③記事本文」タブで本文を一括生成し、Markdown/プレーンテキストでコピー

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に以下を設定
#   ANTHROPIC_API_KEY

# このプロジェクトディレクトリで起動
cd projects/14_seo_article_generator
python app.py
```

ブラウザで http://127.0.0.1:5014 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask（Flask-WTF CSRF） |
| AI生成 | Anthropic Claude API（claude-haiku-4-5）— アウトライン生成・本文生成の2回呼び出し |
| Markdown表示 | フロントエンド側の独自JS変換（`markdownToHtml`） |

## 注意事項

- 目標文字数は500〜5000字の範囲にサーバー側でクランプされます
- アウトラインのJSONパースに失敗した場合はエラーになるため、Claudeの出力形式（コードブロック有無）の変化に注意が必要です
