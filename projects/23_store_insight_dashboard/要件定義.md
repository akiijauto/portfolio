# 要件定義 — Project 23: 店舗改善インサイトダッシュボード

## 目的
日々の売上・客数・スタッフ人数といった簡単な店舗データと、現場からのメモ（気づき・クレーム等）を
入力するだけで、Claude AIがデータの傾向を分析し、改善アクションを提案するダッシュボードを提供する。

## 画面構成（2タブ）

### ①データ入力
- 日次データ（最大31日分）をテーブル形式で入力: 日付・売上(円)・客数(人)・スタッフ人数
  - 行の追加・削除が可能
  - 「サンプルデータを読み込む」ボタンでデモ用の7日分のデータとメモを一括入力できる
- 現場からのメモ・気づき（任意・1000文字以内、文字数カウンタ表示）
- 「AIで分析する」ボタンで②に遷移

### ②ダッシュボード
- 売上・客数の推移を折れ線グラフ(Chart.js、デュアル軸)で表示
- AIによる傾向の要約
- 「良い点」「気になる点」のリスト
- 改善アクション提案（タイトル・内容・優先度バッジ）

## API
### POST /api/analyze
- リクエスト: JSON `{records: [{date, sales, customers, staff}], notes}`
  - records: 1件以上31件以内、各項目は文字列(date)・0以上の整数(sales/customers/staff)
  - notes: 1000文字以内
- 成功時: `{"ok": true, "result": {trend_summary, good_points, concern_points, improvement_actions}}`
- 失敗時: `{"ok": false, "error": "..."}`（shared/errors.pyのエラーメッセージ）

## 技術構成
- Flask（Flask-WTF CSRF）
- Claude API（claude-haiku-4-5、shared/utils.call_claude_json）
- Chart.js（CDN）— 売上・客数のデュアル軸折れ線グラフ

## 成功条件
- サンプルデータ読み込み→AI分析→ダッシュボード表示までが一連の流れで動作する
- AIがデータから読み取れない内容を断定せず、空配列で返した場合は「該当する項目はありません」と表示される
- データは保存されず、ページを離れると消える（ステートレス）
