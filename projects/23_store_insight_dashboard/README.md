# 店舗改善インサイトダッシュボード

日々の売上・客数・スタッフ人数のデータと現場のメモを入力するだけで、Claude AIが傾向を分析し、
改善アクションを提案するダッシュボードです。

## できること

1. **データ入力** — 日付・売上・客数・スタッフ人数を最大31日分テーブルで入力（行の追加・削除可）
2. **サンプルデータ読み込み** — デモ用の7日分のデータとメモをワンクリックで入力
3. **AI分析** — Claude AIが傾向を分析し、傾向の要約・良い点・気になる点・改善アクション（優先度付き）を生成
4. **ダッシュボード表示** — 売上・客数の推移をChart.jsの折れ線グラフで可視化

## 使い方

1. 「①データ入力」タブで日次データを入力（「サンプルデータを読み込む」でデモ可能）
2. 「現場からのメモ・気づき」に気になっていることを記入（任意）
3. 「AIで分析する」をクリックすると「②ダッシュボード」に切り替わり、グラフと改善提案が表示される

## ディレクトリ構成

```
23_store_insight_dashboard/
├── app.py          … Flaskアプリ本体（ルーティング・入力検証）
├── generator.py    … Claudeへの分析プロンプト
├── templates/
│   └── index.html
└── static/
    ├── app.js       … 入力テーブル管理・Chart.js描画・AI分析
    └── style.css
```

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に以下を設定
#   ANTHROPIC_API_KEY

# このプロジェクトディレクトリで起動
cd projects/23_store_insight_dashboard
python app.py
```

ブラウザで http://127.0.0.1:5023 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask（Flask-WTF CSRF） |
| AI生成 | Anthropic Claude API（claude-haiku-4-5） — データ傾向分析・改善アクション生成 |
| グラフ | Chart.js（CDN） — 売上・客数のデュアル軸折れ線グラフ |

## 注意事項

- 入力データは最大31日分、メモは1000文字以内です
- データはブラウザのセッション内のみ保持され、永続化は行いません
- AIによる提案は参考情報であり、最終的な判断は店舗側で行ってください
