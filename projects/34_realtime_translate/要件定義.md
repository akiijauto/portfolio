# 要件定義 — Project 34: 多言語リアルタイム翻訳チャット

## 概要
チャット入力を即座に日・英・中・韓の4言語へ翻訳し、SSE（Server-Sent Events）で
ブラウザへリアルタイムにストリーミング表示する翻訳チャットアプリ。

## 機能要件
1. チャット欄にテキストを入力して送信する
2. Gemini APIのストリーミングモードで4言語（日本語・English・中文・한국어）へ翻訳する
3. 翻訳結果を言語ごとにSSEでリアルタイムにストリーミング表示する（生成中の文字が
   逐次画面に追加される）
4. 原文・4言語の翻訳結果を並べて表示するレイアウト
5. 翻訳履歴をSQLiteへ保存し、画面下部に一覧表示する
6. 各翻訳結果をワンクリックでコピーできる

## データ構造
SQLite（`instance/translate_history.db`）に以下のテーブルを持つ。

| カラム | 型 | 説明 |
|---|---|---|
| id | INTEGER PK | 自動採番 |
| original_text | TEXT | 入力された原文 |
| ja / en / zh / ko | TEXT | 各言語の翻訳結果 |
| created_at | TEXT | 作成日時（UTC, ISO8601） |

## 画面構成
- `/` — チャット入力フォーム・翻訳結果表示エリア・翻訳履歴一覧
- `/translate`（POST, SSE） — Gemini APIのストリーミング応答をSSE形式
  （`event: start/chunk/done/error/complete`）で返す

## 技術スタック
Flask（`Response`によるchunked streaming） / Gemini API（`google-genai`の
`generate_content_stream`） / SQLite（標準`sqlite3`モジュール） / Render

## 成功条件
- テキスト未入力時はエラーメッセージを表示する
- `GEMINI_API_KEY`未設定時はエラーメッセージを表示し、処理が落ちない
- 4言語すべての翻訳結果がストリーミングで画面に表示される
- 翻訳完了後、履歴に1件追加され、リロード後も表示される
