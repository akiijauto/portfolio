# 要件定義書 — Sprint #4: 家計簿ダッシュボード

## 概要

認証付きの個人家計簿アプリ。収支を登録し、カテゴリ別・月別の集計グラフをダッシュボードで可視化する。

## 新技術（このスプリントで習得）

| 技術 | 概要 |
| --- | --- |
| SQLAlchemy `func.sum` + `group_by` | 集計クエリ（SUM / GROUP BY） |
| SQLAlchemy 3テーブル設計 | User → Category → Transaction の階層FK |
| Chart.js | ブラウザ側で棒グラフ・ドーナツグラフを描画 |

## 機能要件

### 認証（Sprint #1 の07_memo_appと共通パターン）
- ユーザー登録 / ログイン / ログアウト
- 自分のデータのみ参照・操作可能

### カテゴリ管理
- カテゴリ（食費・交通費・娯楽など）の追加・削除
- 各ユーザーが独自のカテゴリを持つ

### 収支登録
- 日付・金額・カテゴリ・メモを入力して登録
- 一覧表示（最新20件）
- 削除

### ダッシュボード（集計表示）
- 当月合計支出
- カテゴリ別支出ドーナツグラフ（Chart.js）
- 直近6ヶ月の月別支出棒グラフ（Chart.js）

## データモデル

```
User (07_memo_appと同じ構造)
├── id, email, password_hash, created_at
│
├── categories (1対多)
│   └── Category
│       ├── id, user_id(FK), name, color(#hex)
│       └── transactions (1対多)
│           └── Transaction
│               ├── id, user_id(FK), category_id(FK)
│               ├── amount (Integer, 円)
│               ├── date (Date)
│               └── memo (String, optional)
│
└── transactions (直接参照用)
    └── Transaction ↑
```

## 画面構成

| ルート | 説明 |
| --- | --- |
| `GET /` | ダッシュボード（集計グラフ + 最新取引） |
| `GET/POST /login` | ログイン |
| `GET/POST /register` | 新規登録 |
| `POST /logout` | ログアウト |
| `GET/POST /transactions/new` | 収支登録 |
| `POST /transactions/<id>/delete` | 削除 |
| `GET/POST /categories` | カテゴリ一覧・追加 |
| `POST /categories/<id>/delete` | カテゴリ削除 |
| `GET /api/chart/donut` | カテゴリ別集計 JSON（Chart.js用） |
| `GET /api/chart/bar` | 月別集計 JSON（Chart.js用） |

## 技術スタック

- Flask + Flask-Login + Flask-WTF（CSRF）
- Flask-SQLAlchemy（SQLite）
- Chart.js（CDN）
- 共通: `shared/csrf_setup.py`、`shared/base.css`

## 成功条件

1. 収支を登録してカテゴリ別ドーナツグラフに反映される
2. 6ヶ月分の月別棒グラフが正しく集計される
3. ユーザーAのデータがユーザーBには見えない（データ分離）
4. ローカル起動 `python app.py` → ポート 5010 で動作
