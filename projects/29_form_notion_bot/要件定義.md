# 要件定義 — Project 29: Webフォーム→Notion自動転記Bot

## 概要
Webフォームに入力された問い合わせ・申込内容を受信し、Gemini AIで要約・カテゴリ分類
してからNotionデータベースへ自動保存し、管理者へ通知メール・送信者へ自動返信メールを
送るBot。

## 機能要件
1. Webフォーム（名前・メール・用件・詳細）を受信する
2. Gemini APIが用件・詳細を要約し、5カテゴリ（新規お問い合わせ／サポート依頼／申込み／
   クレーム／その他）のいずれかに分類する
3. Notion DBへ自動追記する（カラム: 日時・名前・メール・用件・カテゴリ・要約・ステータス）
4. 管理者メールアドレス（`ADMIN_EMAIL`）へsmtplibで通知メールを送る
5. フォーム送信者へ自動返信メールを送る
6. AI分類に失敗した場合は「その他」カテゴリへフォールバックし、処理を継続する
7. Notion保存に失敗した場合はユーザーへエラーを表示し、メール送信は行わない
8. メール送信（管理者通知・自動返信）が失敗しても、フォーム送信自体は成功として扱う
   （Notionへの保存が完了していれば、後から手動でフォローアップできるため）

## データ構造（Notion DB）

| プロパティ名 | 型 | 説明 |
|---|---|---|
| 名前 | title | 送信者名 |
| メール | email | 送信者メールアドレス |
| 用件 | rich_text | フォームの「用件」欄 |
| カテゴリ | select | AIが分類した5カテゴリのいずれか |
| 要約 | rich_text | AIが生成した2〜3文の要約 |
| ステータス | select | 新規／対応中／完了（初期値は「新規」） |
| 日時 | date | 受信日時（UTC） |

実機テストでは「AI開発ポートフォリオ」配下に専用DB
（https://app.notion.com/p/09fafc5420d34285807f0399ff2ee50a）を作成し、実際に1件保存・
取得・アーカイブして動作を確認した。

## 画面構成
- `/` — お問い合わせフォーム（名前・メール・用件・詳細）
- `/submit`（POST） — 入力検証 → AI分類 → Notion保存 → メール送信

## 技術スタック
Flask / smtplib + email / Notion API（`notion-client`） / Gemini API
（`shared.utils.call_claude_json`経由） / Render

## 成功条件
- 入力検証エラー時はフォームに戻りエラーメッセージを表示する
- Gemini APIが利用不可・分類失敗時も「その他」カテゴリで保存を継続する
- Notion DBへの保存が実機で確認できる
- メール送信失敗時もフォーム送信自体は成功として扱われる
