# 要件定義 — Project 28: QRコード名刺メーカー

## 概要
名前・肩書き・連絡先などを入力すると、QRコード（vCard形式）付きのデジタル名刺をPDF形式で
生成・ダウンロードできるWebアプリ。

## 機能要件
1. 名前（必須）・肩書き・会社名・メール・電話・URLを入力フォームで受け付ける
2. 入力情報からvCard形式のQRコードを生成する
3. Pillowで名刺レイアウト（91mm×55mm相当、300dpi換算）に情報とQRコードを合成する
4. ReportLabでPDF化し、ブラウザからダウンロードさせる
5. （オプション）Gemini APIで名刺に添えるキャッチコピーを1行自動生成する

## データ構造
DBは使用しない。フォーム入力をそのまま画像・PDF生成に使い、サーバー側には保存しない。

## 画面構成
- `/` — 入力フォーム（名前・肩書き・会社・メール・電話・URL・キャッチコピー生成チェックボックス）
- `/generate`（POST） — フォーム送信を受けPDFを生成しダウンロードさせる

## 技術スタック
Flask / qrcode[pil] / Pillow / reportlab / Gemini API（`shared.utils.call_claude_text`経由） / Render

## 成功条件
- 必須項目（名前）が空の場合はエラーメッセージを表示し再入力を促す
- 生成されたQRコードをスマートフォンで読み取るとvCardとして連絡先に取り込める
- PDFが91mm×55mmの名刺サイズで正しく出力される
- キャッチコピー生成チェックを入れた場合、Gemini APIキー未設定でもエラーにならず空欄のまま続行する
