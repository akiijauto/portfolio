# 11_webhook_relay 振り返り

## 開発中に発生した課題と解決策

### HMAC署名検証でタイミング攻撃を防ぐ
- **課題**: 単純な文字列比較（`==`）でHMAC署名を検証すると、比較時間の差からシークレットが推測されるタイミング攻撃のリスクがある
- **解決**: `hmac.compare_digest()` を使って定数時間比較にした。セキュリティ上必須の実装であることを学んだ

### GitHubから届くペイロードのイベント種別の判定
- **課題**: `X-GitHub-Event` ヘッダーを見るだけでは `pull_request` の「merge」なのか「close」なのか区別できない
- **解決**: `action == 'closed'` かつ `payload['pull_request']['merged'] == True` の両方を確認することでmergeを判定した

### Discordへの送信失敗時の処理
- **課題**: Discord Webhookへの送信が失敗してもGitHubへは必ず200を返す必要がある（GitHub側でリトライが発生するのを避けるため）
- **解決**: Discord POST を try/except で包み、失敗はログに記録するだけにして、レスポンスは常に200を返すようにした
