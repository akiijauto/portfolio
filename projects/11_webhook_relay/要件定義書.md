# 要件定義書 — Sprint #5: GitHub → Discord Webhook中継サーバー

## 概要

GitHubからWebhookを受信し、HMAC-SHA256署名を検証してDiscordにEmbed通知を送信する中継サーバー。受信ログをUIで確認できる。

## 新技術（このスプリントで習得）

| 技術 | 概要 |
| --- | --- |
| HMAC-SHA256署名検証 | `hmac.compare_digest` + `hashlib.sha256` でGitHub署名ヘッダーを検証 |
| GitHubイベントルーティング | `X-GitHub-Event` ヘッダーでイベント種別を判別し、メッセージを整形 |
| Discord Embed API | `embeds` フィールドでリッチなカード通知を送信 |

## 機能要件

### Webhook受信エンドポイント（`POST /webhook/github`）
- `X-Hub-Signature-256` ヘッダーをHMAC-SHA256で検証（署名不一致 → 403）
- 対応イベント:
  - `push` — ブランチ名・コミット数・最新コミットメッセージをEmbed送信
  - `pull_request` — PR番号・タイトル・アクション(opened/closed/merged)をEmbed送信
  - `issues` — Issue番号・タイトル・アクションをEmbed送信
  - `ping` — 疎通確認（200 OK のみ）
  - 未対応イベント — ログのみ記録して200 OK
- 受信ログをメモリに保持（最新50件）

### 管理UI（`GET /`）
- 受信ログ一覧（日時・イベント種別・結果・概要）
- Webhook URLと設定手順の表示

## 画面構成

| ルート | 説明 |
| --- | --- |
| `GET /` | 管理UI（ログ一覧・設定手順） |
| `POST /webhook/github` | GitHubからのWebhook受信（CSRF除外） |
| `GET /api/logs` | ログJSON（UI自動更新用） |

## 技術スタック

- Flask + Flask-WTF（CSRF: /webhook/github を除外）
- `hmac` + `hashlib`（標準ライブラリ、追加インストール不要）
- `requests` — Discord Embed POST
- 環境変数: `GITHUB_WEBHOOK_SECRET`, `DISCORD_WEBHOOK_URL`

## 成功条件

1. 正しい署名のcurlリクエスト → Discord Embedが届く
2. 不正な署名のcurlリクエスト → 403が返る
3. 管理UIにログが表示される
