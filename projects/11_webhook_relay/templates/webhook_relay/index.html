GitHub への設定手順
  1. GitHubリポジトリ → Settings → Webhooks → Add webhook
  2. Payload URL に上記URLを入力
  3. Content type を application/json に変更
  4. Secret に GITHUB_WEBHOOK_SECRET 環境変数と同じ値を入力
  5. Events で通知したいイベントを選択（push / pull_request / issues）
  6. Add webhook → ping イベントが届いてログに表示されれば成功

対応イベント: push / pull_request / issues / ping
