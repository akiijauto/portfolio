# 振り返り — Project 16: 広告文生成ツール

## 発生した課題と解決策

### 1. 3媒体分を別々にAPI呼び出しすると遅い・コストが増える
**課題:** Google/Meta/LINEの広告文をそれぞれ別のClaude API呼び出しで生成すると、レスポンスが遅くなり、
APIコストも3倍になる。

**解決策:** `generate_all()` で1回のAPI呼び出しにまとめ、プロンプト内で3媒体分のJSON構造（`google`/`meta`/`line`/`ab_variants`/`copy_points`）を
一度に指定して生成するようにした。媒体ごとの特性（Googleはキーワード重視、Metaは感情訴求、LINEは親しみやすさ）も
同じプロンプト内に列挙することで、1回の呼び出しでも各媒体らしい文面になるようにした。

### 2. Claudeの応答にコードフェンスが付く問題
**課題:** Project 13〜15と同様、JSON形式のレスポンスを期待しているが、Claudeの出力が
`` ```json ``` ``で囲まれて返ってくることがある。

**解決策:** 同じパターンで `` ``` `` を含む場合は `split("```")[1]` でコードブロック内側を取り出し、
先頭が `json` であれば除去してから `json.loads()` するようにした。

### 3. 文字数制限の定義（`AD_LIMITS`）が未使用のまま残っている
**課題:** `generator.py` に各媒体の文字数制限を定義した `AD_LIMITS` 辞書を用意したが、
実際のプロンプトでは個別に文字数（30文字以内・90文字以内など）をハードコードしており、`AD_LIMITS` 自体は参照されていない。

**解決策（今後の対応）:** 動作には影響しないため一旦そのままにしているが、将来的に
生成結果の文字数バリデーション（Claudeが指定文字数を超えて生成した場合の警告表示など）を追加する際に
`AD_LIMITS` を参照する形にリファクタリングする想定。
