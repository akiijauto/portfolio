# 広告文生成ツール

商品・サービス情報を入力するだけで、Google検索広告・Meta広告・LINE広告の3媒体分の広告文をAIが一括生成します。
A/Bテスト用のバリエーションも同時に生成されます。

## できること

1. **3媒体一括生成** — Google検索広告（見出し10本＋説明文4本）、Meta広告（プライマリテキスト/見出し/説明文/CTA案）、LINE広告（タイトル/テキスト）を1回の操作で生成
2. **媒体特性に合わせた広告文** — Googleは検索意図・キーワード重視、Metaは感情訴求、LINEは親しみやすさ・地域密着感を意識した文面
3. **A/Bバリエーション** — Google見出しの別案（感情訴求 or 数字強調）、Metaプライマリテキストの別案
4. **コピーのポイント解説** — 生成された広告文が効果的な理由をAIが解説
5. **コピー機能** — 媒体ごとに「全コピー」ボタンでテキストをまとめてコピー可能

## 使い方

1. 「①商品・サービス情報」タブで商品名・ターゲット・強み（USP）・業界・広告目的を入力
2. 「🚀 3媒体の広告文を一括生成」ボタンをクリック
3. 「②広告文一覧」タブでGoogle/Meta/LINEそれぞれの広告文・A/Bバリエーション・コピーのポイントを確認

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に以下を設定
#   ANTHROPIC_API_KEY

# このプロジェクトディレクトリで起動
cd projects/16_ad_copy_generator
python app.py
```

ブラウザで http://127.0.0.1:5016 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask（Flask-WTF CSRF） |
| AI生成 | Anthropic Claude API（claude-haiku-4-5） — 3媒体分を1リクエストで一括生成 |

## 注意事項

- 商品・サービス名は100文字以内、ターゲットは100文字以内、強み・USPは300文字以内に制限されています
- USPを具体的に（数字・期間・保証など）書くほど、生成される広告文の精度が上がります
