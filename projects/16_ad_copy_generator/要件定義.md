# 要件定義 — Project 16: 広告文生成ツール

## 概要

商品・サービス情報を入力するだけで、Google検索広告・Meta広告・LINE広告の3媒体分の広告文をClaude AIが一括生成するツール。
各媒体の文字数制限・特性に合わせた広告文に加え、A/Bテスト用のバリエーションも同時に生成する。
Phase 3 Priority 4として実装。

## 機能要件

### ① 商品・サービス情報
- 商品・サービス名（必須・100文字以内）、ターゲット（必須・100文字以内）、強み・USP（必須・300文字以内）、業界・ジャンル（任意）、広告の目的（認知拡大／リード獲得／購入・成約／来店・予約）を入力

### ② 広告文一覧
- 入力内容をもとに、Claudeが以下を1回のAPI呼び出しでJSON形式で一括生成
  - **Google検索広告**: 見出し10本（30文字以内）、説明文4本（90文字以内）
  - **Meta広告**: プライマリテキスト（125文字以内）、見出し（40文字以内）、説明文（30文字以内）、CTAボタン案3つ
  - **LINE広告**: タイトル（40文字以内）、テキスト（240文字以内）
  - **A/Bバリエーション**: Google見出しの別案（感情訴求/数字強調）、Metaプライマリテキストの別案
  - **コピーのポイント**: この広告文が効果的な理由の解説
- 各媒体ごとに「全コピー」ボタンでテキストをまとめてコピー可能

## データ構造・API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/generate` | POST | 3媒体分の広告文を一括生成（`product`, `target`, `usp`, `industry`, `goal`） |

レスポンスJSON構造:
```json
{
  "google": {"headlines": ["...x10"], "descriptions": ["...x4"]},
  "meta": {"primary_text": "...", "headline": "...", "description": "...", "cta_options": ["...x3"]},
  "line": {"title": "...", "text": "..."},
  "ab_variants": {"google_alt_headline": "...", "meta_alt_primary": "..."},
  "copy_points": "..."
}
```

## 画面構成（タブ）

1. **①商品・サービス情報** — 商品名/ターゲット/USP/業界/広告目的（チップ選択）の入力フォーム
2. **②広告文一覧** — Google/Meta/LINEの各カード（見出し・説明文・A/Bバリエーション）+ コピーのポイント

## 技術スタック

- Flask + Flask-WTF（CSRF）
- Anthropic Claude API（claude-haiku-4-5） — 3媒体分を1リクエストで一括生成
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `static/base.css`

## 成功条件

1. 商品名・ターゲット・USPを入力すると、Google/Meta/LINEの3媒体分の広告文が生成される
2. Google見出しが10本、説明文が4本、それぞれ文字数制限内で生成される
3. A/Bバリエーション（Google見出し・Meta本文の別案）が生成される
4. ローカル起動 `python app.py` → ポート 5016 で動作
