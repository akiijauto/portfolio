# シフト作成アシスタントAI

スタッフの希望条件（出勤可能曜日・希望勤務時間・週の上限時間）と、曜日別の必要人数・営業時間を入力すると、
Claude AIが1週間分のシフト案を自動作成するWebアプリです。

## 使い方
1. 「①条件入力」タブでスタッフ一覧と曜日別の必要人数を入力します。
   - 「サンプルデータを読み込む」ボタンで、デモ用のデータを一括入力できます。
2. 「AIでシフトを作成する」を押すと、AIが1週間分のシフト案を生成します。
3. 「②シフト案」タブに、曜日別の担当者・勤務時間・休憩時間、確認が必要な点、改善提案が表示されます。

## 起動方法
```bash
python app.py
```
`http://127.0.0.1:5024` で起動します。

## 技術構成
- Flask + Flask-WTF（CSRF対策）
- Claude API（claude-haiku-4-5）でシフト案・確認事項・改善提案をJSON形式で生成
- フロントエンドはタブ切り替え式の単一ページ（Vanilla JS）

## 注意事項
本アプリが生成するシフト案は**ドラフト（案）**です。労働基準法等の法令適合性については、
最終的に人による確認・調整が必要です。
