# 要件定義 — Project 24: シフト作成アシスタントAI

## 背景・目的
店舗運営において、スタッフの希望条件（出勤可能曜日・希望勤務時間・週の上限時間）と曜日別の必要人数を
すり合わせてシフトを組む作業は手間がかかり、調整漏れや偏りが発生しやすい。
Claude AIにこれらの条件を渡し、1週間分のシフト案・確認が必要な点・改善提案を自動生成することで、
シフト作成の初期ドラフト作成を支援する。

## 主な機能
1. **条件入力**
   - スタッフ一覧（最大20名）: 氏名・出勤可能曜日・希望勤務時間・週の上限時間
   - 曜日別の営業時間・必要人数（月〜日）
   - 追加の考慮事項（自由記述、任意）
   - 「サンプルデータを読み込む」で1クリックでデモデータを入力可能
2. **AIによるシフト案生成**
   - 曜日ごとの担当者・勤務時間・休憩時間を含むシフト表
   - 各曜日の人員配置が十分か（staffing_ok）の判定
   - 労働時間・必要人数などで確認が必要な点（concerns）
   - シフト作成・運用上の改善提案（suggestions）

## 入力・出力仕様
### `POST /api/generate`
- リクエスト: `{ "staff": [...], "requirements": [...], "notes": "..." }`
  - `staff[]`: `{ name, available_days, preferred_hours, max_hours }`（最大20件）
  - `requirements[]`: `{ day, open_hours, required_count }`（最大7件）
  - `notes`: 1000文字以内
- レスポンス: `{ "ok": true, "result": { shift_plan[], concerns[], suggestions[] } }`
  - `shift_plan[]`: `{ day, assignments: [{name, time, break}], staffing_ok, note }`

## 設計上の注意点
- 労働基準法上の休憩時間（6時間超で45分、8時間超で1時間）への配慮をプロンプトで明示するが、
  最終的な法令適合性の判断は人間が行う前提とし、AIは「確認が必要な点」として提示するに留める。
- データから判断できない内容は空文字・空配列で返し、画面側でも「該当する項目はありませんでした」と表示する。
