# 音声入力式 日報・引継ぎ自動整形

音声入力（またはテキスト入力）した1日の業務メモを、Claude AIがカテゴリ別の日報・引継ぎ事項に自動整理するツールです。

## できること

1. **音声入力** — ブラウザの音声認識機能（Web Speech API）でその日の業務内容を話すだけでテキスト化（テキスト入力も可）
2. **AI整形** — Claude AIが入力内容を「本日のまとめ」「来客・売上の様子」「問題・クレーム・トラブル」「在庫・発注関連」などのカテゴリに整理
3. **引継ぎ事項の抽出** — 翌日以降のスタッフに伝えるべき事項を重要度の高い順に箇条書きで抽出
4. **コピー・ダウンロード** — 整形結果をそのままコピー、またはテキストファイルとしてダウンロード

## 使い方

1. 「①入力」タブで日付・記入者を入力し、🎤ボタンで音声入力（またはテキストエリアに直接入力）
2. 「AIで日報を整理する」をクリック
3. 「②整形済み日報」タブで整理結果を確認し、必要に応じてコピー・ダウンロード

## ディレクトリ構成

```
20_voice_report/
├── app.py          … Flaskアプリ本体（ルーティング）
├── generator.py    … Claudeへの日報整形プロンプト
├── templates/
│   └── index.html
└── static/
    ├── app.js       … 音声入力(Web Speech API)・整形結果表示
    └── style.css
```

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に以下を設定
#   ANTHROPIC_API_KEY

# このプロジェクトディレクトリで起動
cd projects/20_voice_report
python app.py
```

ブラウザで http://127.0.0.1:5020 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask（Flask-WTF CSRF） |
| 音声入力 | ブラウザ標準 Web Speech API（`SpeechRecognition`、サーバー側での音声処理なし） |
| AI生成 | Anthropic Claude API（claude-haiku-4-5） — メモの整理・引継ぎ事項抽出 |

## 注意事項

- 音声入力はChromeなど Web Speech API 対応ブラウザでのみ利用できます（未対応ブラウザではテキスト入力のみ）
- 業務内容メモは3000文字以内に制限されています
- AIは入力内容にない情報を補完・創作しないよう設計していますが、整形結果は必ず内容を確認してください
- データの永続化は行わないステートレスなツールです
