# 要件定義 — Project 20: 音声入力式 日報・引継ぎ自動整形

## 概要

PROJECT 18・19に続く「店舗運営・教育支援（バックエンド領域）」の第3弾。
スタッフがその日の業務内容を音声入力（またはテキスト入力）するだけで、Claude AIが内容を
「来客・売上の様子」「問題・クレーム・トラブル」「在庫・発注関連」などのカテゴリに整理し、
翌日以降のスタッフへの引継ぎ事項を抽出する日報作成支援ツール。
ブラウザ標準のWeb Speech APIで音声をテキスト化し、Claudeが口語表現を整理・構造化するという
「ブラウザ機能＋AI整形」の組み合わせが特徴。

## 機能要件

### ① 入力
- 日付（デフォルトは本日）・記入者名（任意）を入力
- 業務内容メモを入力（必須・3000文字以内）
  - 🎤ボタンでWeb Speech API（`SpeechRecognition`/`webkitSpeechRecognition`、`lang=ja-JP`）による
    音声入力を開始/停止し、認識結果をテキストエリアに追記
  - 音声入力に対応していないブラウザではテキスト入力のみで利用可能
- 「AIで日報を整理する」でClaudeに整形を依頼し②へ

### ② 整形済み日報
- Claudeが入力内容を以下に整理して表示:
  - 本日のまとめ（2〜3文の要約）
  - カテゴリ別整理（来客・売上の様子／良かった点・うまくいったこと／問題・クレーム・トラブル／在庫・発注関連／その他連絡事項。言及がない項目は非表示）
  - 引継ぎ事項（翌日以降のスタッフへの箇条書き、重要度の高い順）
- コピー・テキストファイルダウンロードに対応
- 「入力に戻る」で①へ戻り再編集可能

## データ・API連携

### アプリ内API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/api/format` | POST | 日報整形（`raw_text`, `staff_name`, `report_date`） |

## 画面構成（タブ）

1. **①入力** — 日付・記入者・業務内容メモ（音声入力対応）→ AI整形ボタン
2. **②整形済み日報** — 本日のまとめ・カテゴリ別整理・引継ぎ事項・コピー/ダウンロード

## 技術スタック

- Flask + Flask-WTF（CSRF）
- ブラウザ標準 Web Speech API（音声→テキスト、サーバー側での音声処理なし）
- Anthropic Claude API（claude-haiku-4-5） — メモの整理・引継ぎ事項抽出
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `shared/utils.py`（`call_claude_json`）, `static/base.css`

## 成功条件

1. 業務内容メモを入力して「AIで日報を整理する」を実行すると、本日のまとめ・カテゴリ別整理・引継ぎ事項が表示される
2. 言及されていないカテゴリは表示されず、内容の創作・補完が行われない
3. 整形結果をコピー・テキストファイルとしてダウンロードできる
4. ローカル起動 `python app.py` → ポート 5020 で動作（永続化データは持たないステートレスツール）
