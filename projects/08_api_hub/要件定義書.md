# 外部API連携ハブ 要件定義書

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| システム名 | 外部API連携ハブ |
| 目的 | 「外部API呼び出し・エラーハンドリング・TTLキャッシュ」を学ぶための小規模Webアプリを作る |
| 想定利用者 | 開発者本人（学習目的）。将来は受託案件の外部API連携実装の雛形として使う |
| 公開URL | http://127.0.0.1:5008 （ローカル動作。今後デプロイ予定） |
| 関連リポジトリ | （既存リポジトリ akiijauto/sns-auto-post に追加） |

## 2. 背景・課題

- これまでのプロジェクトでは Claude API・Notion API といった「Pythonライブラリ付きの外部サービス」しか使っていなかった
- 受託でよく求められる「HTTPリクエストで外部APIを叩き、レスポンスをパースして画面に出す」基礎的なパターンを習得していない
- 「同じ入力に対して何度もAPIを叩かないキャッシュ設計」も実務では必須だが経験がない
- 天気・為替・ニュースという身近な題材で、APIの特性（更新頻度・エラーの種類）も一緒に学ぶ

## 3. 利用シナリオ

**対象**：アプリの利用者本人

**ケース A（天気）**：今日の東京の天気を知りたい
1. 「天気」タブで都市名「Tokyo」を入力して検索する
2. 現在の気温・天気・風速が表示される
3. 10分以内に同じ都市を再検索すると、APIを叩かずキャッシュから即座に返す

**ケース B（為替）**：1ドル何円かを確認したい
1. 「為替」タブで通貨ペアを選択（例：USD → JPY・金額 1000）
2. 最新レートと換算結果が表示される
3. 同一ペアは1時間キャッシュされる

**ケース C（ニュース要約）**：NHKの最新ニュースをまとめて把握したい
1. 「ニュース」タブで「要約する」ボタンを押す
2. NHKのRSSから最新5件の見出しと概要を取得し、Claude APIが日本語で3行にまとめる
3. 30分キャッシュされるため、短時間に複数回押してもAPIコストが発生しない

## 4. 成功指標

| 指標 | 内容 |
| --- | --- |
| 外部API呼び出し | 天気・為替・ニュースRSSの3種類を `requests` で取得できる |
| エラーハンドリング | タイムアウト・HTTPエラー・JSON解析失敗をすべてキャッチし、画面にわかりやすいメッセージを出す |
| TTLキャッシュ | 同一キーへの再リクエストはAPI呼び出しなしで返せる |
| 学習目標 | 「外部APIを叩く → パース → エラー処理 → キャッシュ」の一連のパターンを理解し、次の案件で再利用できる状態にする |

## 5. 対象範囲（スコープ）

### 5.1 対象に含む
- Open-Meteo API による都市の天気取得（APIキー不要・無料）
- Frankfurter API による為替レート取得（APIキー不要・無料）
- NHK RSS + Claude API によるニュース見出し要約
- 各APIのTTLキャッシュ（インメモリ、dict + timestamp）
- タイムアウト・HTTPエラー・接続エラーのエラーハンドリング

### 5.2 対象外
- ユーザー認証（今回は認証なし）
- 永続的なデータ保存（DBなし、キャッシュはメモリのみ）
- 過去の履歴や統計の表示
- 天気予報（今回は現在の天気のみ）

## 7. 運用フロー

```
ユーザー（ブラウザ）
        ↓（AJAX POSTリクエスト）
Flask（APIルーティング）
        ↓
fetchers.py（キャッシュ確認 → キャッシュHIT: 即返却 / MISS: 外部API呼び出し）
        ↓（キャッシュMISSの場合）
外部API（Open-Meteo / Frankfurter / NHK RSS + Claude）
        ↓
ユーザー（結果をJSONで受け取りJSで画面に表示）
```

## 8. 画面構成（UI）

3タブ構成のシングルページアプリケーション：

1. **①天気タブ**：都市名入力欄 → 「検索」ボタン → 気温・天気・風速を表示
2. **②為替タブ**：通貨ペア選択（from/to）・金額入力 → 「換算」ボタン → レートと換算結果を表示
3. **③ニュースタブ**：「最新ニュースを要約する」ボタン → Claude の要約文を表示

## 9. 外部連携・使用技術

| 連携先 | 用途 | APIキー |
| --- | --- | --- |
| Open-Meteo Geocoding API | 都市名 → 緯度経度 | 不要 |
| Open-Meteo Weather API | 現在の天気データ取得 | 不要 |
| Frankfurter API | 為替レート取得 | 不要 |
| NHK RSS（cat0.xml） | ニュース見出し取得 | 不要 |
| Claude API（claude-haiku-4-5） | ニュース見出しの要約生成 | 既存の ANTHROPIC_API_KEY を使用 |
| requests | HTTPクライアント（既にrequirements.txtに存在） | — |
| BeautifulSoup4 + lxml | RSS（XML）のパース（既存） | — |

## 10. 非機能要件

| 項目 | 内容 |
| --- | --- |
| パフォーマンス | タイムアウトは5秒。キャッシュHIT時は即座に返す |
| セキュリティ | APIキー（ANTHROPIC_API_KEY）は`.env`で管理。新規APIキーは今回なし |
| エラーハンドリング | 外部APIが落ちていても画面がエラーのまま固まらず、日本語でメッセージを表示する |
| CSRF対策 | AJAX経由のため、X-CSRFToken ヘッダーでトークンを送信する |

## 11. 制約事項・前提条件

- Renderの無料プランはメモリキャッシュがインスタンス再起動でリセットされる（学習用途なので許容）
- Frankfurter APIの基準通貨はEUR固定のため、USD→JPYなど直接変換できない組み合わせはEUR経由で計算する
- NHK RSSのフィードURL変更時は `fetchers.py` の定数を修正すること
