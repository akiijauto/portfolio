# 08_api_hub 振り返り

## 開発中に発生した課題と解決策

### NHK RSSのXML文字コード問題
- **課題**: NHK RSSはUTF-8だが、`requests` が文字コードを自動判定できず文字化けが発生した
- **解決**: `response.encoding = 'utf-8'` を明示的に設定してから `response.text` を渡すことで解決

### TTLキャッシュの実装
- **課題**: 外部APIを毎リクエストで叩くとレート制限・遅延の問題が出る。ライブラリを増やしたくなかった
- **解決**: `{key: (data, timestamp)}` の辞書と `time.time()` の差分でTTLを自前実装。シンプルで十分に機能した

### Claude APIの呼び出しコスト
- **課題**: ニュース要約でAPIを毎回呼ぶとコストがかかる
- **解決**: 30分のTTLキャッシュを設け、同一期間内の2回目以降はAPIを呼ばずキャッシュを返すようにした
