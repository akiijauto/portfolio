# 求人原稿・面接質問自動生成

募集条件（職種・雇用形態・勤務時間・給与・仕事内容など）を入力するだけで、
AIが応募者向けの求人原稿と、面接で使える質問リストを自動生成するツールです。

## 使い方
1. 「①募集情報入力」タブで募集職種・雇用形態・勤務時間・給与・仕事内容などを入力する
   （「サンプルを読み込む」で例を試すこともできます）
2. 「AIで求人原稿を作成する」ボタンを押す
3. 「②求人原稿・面接質問」タブに、求人原稿と面接質問リストが表示される
4. 各カードの「コピー」「ダウンロード」ボタンでテキストとして取得できる

## 起動方法
```bash
python app.py
```
ポート5027で起動します。

## 主な構成
- `app.py`: Flaskアプリ本体、`/api/generate`エンドポイント
- `generator.py`: Claude APIへのプロンプト構築・呼び出し
- `templates/index.html`: 2タブUI
- `static/app.js`: フロントエンドロジック
- `static/style.css` / `static/base.css`: スタイル

## 注意事項
生成された求人原稿・面接質問は、必ず採用担当者が内容を確認・修正してから使用してください。
特に面接質問の「避けるべき質問・注意事項」は一般的な指針であり、最終判断は人が行ってください。
