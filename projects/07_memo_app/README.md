# メモアプリ（認証付き）

ユーザー登録・ログインを備えた、自分専用のメモ管理Webアプリです。
「認証（ユーザー登録・ログイン・パスワードハッシュ化）」と「ユーザーごとのデータ分離」を学ぶための学習用ミニプロジェクトとして作成しました。

> 詳細な仕様は [要件定義書](要件定義書.md) を参照してください。

## 想定ユーザー

- アプリの利用者本人（学習目的）
- 日々のちょっとしたメモを、自分専用のスペースに記録・整理したい個人

## できること

1. **ユーザー登録／ログイン／ログアウト** — メールアドレスとパスワードでアカウントを作成し、ログインできる（パスワードはハッシュ化して保存）
2. **メモのCRUD** — メモの作成・一覧表示・編集・削除ができる
3. **データ分離** — 自分が作成したメモだけが見える・操作できる。他人のメモへのアクセスは拒否される

## 画面イメージ

> （準備中：ログイン画面・メモ一覧・メモ作成編集画面のスクリーンショットを掲載予定）

## 使い方

1. 「新規登録」からメールアドレス・パスワードを入力してアカウントを作成する
2. 作成したアカウントでログインする
3. 「＋ 新規メモ作成」からタイトルと本文を入力して保存する
4. メモ一覧から既存メモの編集・削除を行う
5. ログアウトして別アカウントでログインすると、メモが完全に分離されていることを確認できる

## セットアップ

### 必要要件
- Python 3.x

### 手順

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env.example を参考に .env を作成し、以下を設定
#   SECRET_KEY（セッション・CSRF対策用。未設定でも自動生成されるが本番では必須設定推奨）

# このプロジェクトディレクトリで起動
cd projects/07_memo_app
python app.py
```

ブラウザで http://127.0.0.1:5007 を開いて利用します。初回起動時に `memo_app.db`（SQLite）が自動作成されます。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask |
| 認証 | Flask-Login（セッション管理） |
| パスワード保護 | Werkzeug（generate_password_hash / check_password_hash によるハッシュ化） |
| データ保存 | SQLite + Flask-SQLAlchemy（users / memos の2テーブル構成） |
| CSRF対策 | shared/csrf_setup.py（共通モジュール）を流用 |
| フロントエンド | HTML / CSS（サーバーサイドレンダリング、Jinja2テンプレート） |

## デプロイ

[Render](https://render.com/) への公開手順は [DEPLOY.md](DEPLOY.md) にまとめています（`render.yaml`・`gunicorn`対応済み）。
SQLiteを使用しているため、無料プランではデータが永続化されない点に注意してください（詳細はDEPLOY.md参照）。

## 注意事項

- 学習目的のミニプロジェクトのため、現状はローカル動作のみです
- パスワードは必ずハッシュ化して保存しており、平文では保存・表示しません
- 他ユーザーのメモへの直接アクセス（URL推測等）はサーバー側で拒否する設計になっています
