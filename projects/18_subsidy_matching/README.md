# 補助金・助成金マッチング＆事業計画ドラフト生成

事業内容と地域を入力すると、デジタル庁の補助金・助成金オープンAPI「jGrants」から該当する制度を検索し、Claude AIが適合度診断から事業計画書ドラフトの作成までを一気通貫でサポートします。

## できること

1. **補助金・助成金検索** — 事業内容のキーワードと都道府県を指定し、jGrants APIから募集中の制度を検索
2. **適合判定** — 選択した制度に対し、事業内容を入力するとAIが適合度（0〜100点）・理由・注意点・必要書類・次のアクションを診断
3. **事業計画ドラフト生成** — 適合判定の内容を引き継ぎ、事業概要・課題・解決策・スケジュール・経費・期待効果・申請のポイントを含む事業計画書ドラフトを生成（コピー・ダウンロード可）

## 使い方

1. 「①補助金・助成金検索」タブでキーワード（例: 飲食店 設備導入）と地域を入力して検索
2. 検索結果から「この補助金で診断する」を選択し、「②適合判定」タブで事業内容を入力して診断
3. 診断結果から「③事業計画ドラフトを作成」で事業計画書ドラフトを生成・コピー/ダウンロード

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に以下を設定
#   ANTHROPIC_API_KEY

# このプロジェクトディレクトリで起動
cd projects/18_subsidy_matching
python app.py
```

ブラウザで http://127.0.0.1:5018 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask（Flask-WTF CSRF） |
| 外部API | jGrants 補助金・助成金API（デジタル庁・認証不要） |
| AI生成 | Anthropic Claude API（claude-haiku-4-5） — 適合判定・事業計画ドラフト生成 |

## 注意事項

- jGrants APIのレスポンスはエンコーディングをUTF-8に明示する必要があります（`jgrants_api.py`で対応済み）
- 事業内容は1500文字以内、事業計画で重視したい点は500文字以内に制限されています
- AIによる診断・ドラフトは参考情報です。正式な申請要件・経費の対象範囲は必ず各制度の募集要項本文をご確認ください
- データの永続化は行わないステートレスなツールです
