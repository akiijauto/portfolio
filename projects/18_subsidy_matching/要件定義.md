# 要件定義 — Project 18: 補助金・助成金マッチング＋事業計画ドラフト生成

## 概要

これまでのSEO・SNS・広告・CRM系（集客支援/フロントエンド領域）とは別軸として、店舗経営者の実務課題のうち「資金調達・申請業務」を支援するツール。
事業内容・地域を入力すると、デジタル庁が公開する補助金・助成金オープンAPI「jGrants」から該当制度を検索し、Claude AIが①適合度診断、②申請用の事業計画書ドラフト生成までを一気通貫で行う。
単なる文章生成ではなく「外部APIによる制度検索 → 要件との適合判定 → 事業計画書フォーマットへの構造化」という複合システムである点が特徴。

## 機能要件

### ① 補助金・助成金検索
- 事業内容・キーワード（必須・2〜100文字）と地域（都道府県・任意）を入力
- 「現在募集中のみ表示」チェックでフィルタ
- jGrants公開API（`https://api.jgrants-portal.go.jp/exp/v1/public/subsidies`）から検索し、タイトル・対象エリア・上限額・受付期間・対象従業員数を一覧表示
- 各結果から「この補助金で診断する」を選択して②へ

### ② 適合判定
- 選択した補助金の詳細情報（jGrants詳細API）を取得
- 事業内容（業種・規模・実施したいこと等、必須・1500文字以内）を入力
- Claudeが以下を診断:
  - 適合度スコア（0〜100）とラベル
  - 適合していると考えられる理由
  - 申請前に確認すべき注意点・懸念点
  - 必要になりそうな書類（一般的に求められるものの推定）
  - 次のアクション
- 診断結果から③へ事業内容を引き継いで遷移可能

### ③ 事業計画ドラフト生成
- ②で入力した事業内容（編集可）＋重視したい点（任意・500文字以内）を入力
- Claudeが事業計画書ドラフトを生成:
  - タイトル、事業概要、現状の課題・背景、解決策・実施内容
  - 実施スケジュール（フェーズ／期間／内容の表）
  - 必要経費の概算（項目／金額／補足の表）
  - 期待される効果、申請のポイント
- コピー・テキストファイルダウンロードに対応

## データ・API連携

### 外部API: jGrants（デジタル庁 補助金・助成金API・認証不要）
- 検索: `GET /exp/v1/public/subsidies`（keyword, target_area_search, acceptance, sort, order）
- 詳細: `GET /exp/v1/public/subsidies/id/{id}`（detail本文はHTML→テキスト抽出して使用）
- レスポンスは `resp.encoding = "utf-8"` を明示しないと文字化けするため注意

### アプリ内API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/api/search` | POST | jGrants検索（`keyword`, `prefecture`, `only_open`） |
| `/api/match` | POST | 適合度診断（`subsidy_id`, `business_desc`） |
| `/api/plan` | POST | 事業計画ドラフト生成（`subsidy_id`, `business_desc`, `focus_points`） |

## 画面構成（タブ）

1. **①補助金・助成金検索** — キーワード・地域・募集状況フィルタ → 検索結果カード一覧
2. **②適合判定** — 選択中の補助金表示 + 事業内容入力 → 適合度スコア・理由・注意点・必要書類・次のアクション
3. **③事業計画ドラフト生成** — 事業内容（引き継ぎ）＋重視点入力 → 事業計画書ドラフト（概要/課題/解決策/スケジュール/経費/効果/ポイント）

## 技術スタック

- Flask + Flask-WTF（CSRF）
- jGrants公開API（requests + BeautifulSoupでHTML本文をテキスト化）
- Anthropic Claude API（claude-haiku-4-5） — 適合判定・事業計画ドラフト生成
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `shared/utils.py`（`call_claude_json`）, `static/base.css`

## 成功条件

1. キーワード・地域を入力して検索すると、jGrants APIから該当する補助金・助成金が一覧表示される
2. 検索結果から補助金を選び事業内容を入力すると、適合度診断（スコア・理由・注意点・必要書類・次のアクション）が表示される
3. 適合判定からの事業内容を引き継いで事業計画ドラフトを生成すると、概要・課題・解決策・スケジュール・経費・効果・申請ポイントを含むドラフトが生成される
4. ローカル起動 `python app.py` → ポート 5018 で動作（永続化データは持たないステートレスツール）
