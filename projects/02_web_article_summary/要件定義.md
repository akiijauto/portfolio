# 要件定義 — Project 02: Web記事要約ツール

## 概要

Web記事のURLを入力するだけで、Claudeが「3行要約」「5行要約」「SNS投稿用テキスト」の3パターンを自動生成するツール。
URLが分からない場合は、キーワード検索から記事を探して選択し、そのまま要約できる。

## 機能要件

### ① URL要約
- 記事URLを入力（`http(s)://` 省略時は自動付与）
- `scraper.fetch_article()` で本文・タイトルを取得（article/main/contentクラス優先で抽出）
- 本文が100文字未満の場合はJS動作サイトと判断しエラー表示
- `summarizer.summarize()` でClaudeに3行要約・5行要約・SNS投稿用テキストを生成させる
- 結果はカードごとにコピー可能、全体をテキストファイルでダウンロード可能

### ② キーワード検索→記事選択→要約
- キーワード（200文字以内）を入力
- `scraper.search_articles()` でTavily Search APIを呼び出し、`{title, url, snippet}` の検索結果を最大5件取得
- `TAVILY_API_KEY` 未設定時は503エラーで「URLを直接入力してください」と案内
- 検索結果が0件の場合は404エラーで案内
- 検索結果一覧から1件選択すると、そのURLが「①URL要約」の入力欄に入り、自動で要約が実行される

## データ構造・API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面 |
| `/search` | POST | キーワード検索（`keyword`） → `{ok, results: [{title, url, snippet}]}` |
| `/summarize` | POST | URL要約（`url`） → `{ok, data: {title, summary_3, summary_5, sns, url, char_len}}` |

## エラーハンドリング

- 記事取得失敗（`fetch_article`） → `fetch_failed`
- 本文が短すぎる（JS動作サイト） → `js_site`
- Claude要約失敗 → 通常は `ai_error`、Anthropicクレジット残高不足時は `service_paused`（利用者に謝罪文を表示し、管理者へ自動通知）
- 検索API未設定/失敗 → 503または `fetch_failed`、検索結果0件 → 404

## 技術スタック

- Flask + Flask-WTF（CSRF）
- requests + BeautifulSoup（記事本文取得）
- Anthropic Claude API（claude-haiku-4-5）— `shared.call_claude_json`
- Tavily Search API（`TAVILY_API_KEY`、Project 13と共通パターン）
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `shared/utils.py`（`handle_ai_error`）

## 成功条件

1. URLを入力すると3行要約・5行要約・SNS投稿用テキストが生成される
2. キーワードを入力すると検索結果一覧が表示され、選択した記事がそのまま要約される
3. `TAVILY_API_KEY` 未設定でもURL要約機能は変わらず利用できる
4. Anthropicのクレジット残高不足エラー時は、利用者に「一時的にサービス提供を中断している」旨を表示し、管理者へ自動通知する
5. ローカル起動 `python app.py` → ポート 5002 で動作
