# 要件定義書 — Sprint #6: pytest テストスイート

## 概要

これまでのスプリントで作ったモジュール（webhook.py, fetchers.py, models.py）に対して pytest でユニットテストを書く。モックを使って外部API・DBへの依存を排除したテストを習得する。

その後、Project 13〜17（競合調査ツール・SEO記事生成・SNS運用管理ハブ・広告コピー生成・問い合わせ管理CRM）の追加にあわせてテスト範囲を拡張し、合計139テストとした。

## 新技術（このスプリントで習得）

| 技術 | 概要 |
| --- | --- |
| `pytest` | テストランナー・フィクスチャ・アサーション |
| `unittest.mock.patch` | 外部APIコール・環境変数をモックに差し替え |
| `pytest-flask` | Flaskアプリ用テストクライアント（`app.test_client()`） |
| `conftest.py` | フィクスチャを共有するpytest設定ファイル |

## テスト対象と方針

| 対象 | テスト内容 |
| --- | --- |
| `11_webhook_relay/webhook.py` | HMAC署名検証・各イベントのEmbed生成 |
| `11_webhook_relay/app.py` | `/webhook/github` エンドポイント（正常・403・404） |
| `09_daily_bot/scheduler.py` | Discord送信成功・失敗・シークレット未設定のrun_digest() |
| `10_budget_tracker/models.py` + `app.py` | ユーザー登録・ログイン・収支登録・集計API |
| `13_competitor_research` | DDG検索URL抽出・スクレイピング・AI分析エンドポイント |
| `14_seo_article_generator` | アウトライン/記事生成API・文字数クランプ・コードフェンス除去 |
| `15_sns_management_hub` | ハッシュタグ/バリエーション生成・Notion投稿カレンダー連携 |
| `16_ad_copy_generator` | 全媒体広告文一括生成API・入力バリデーション |
| `17_inquiry_crm` | 問い合わせCRUD（インメモリDB）・AI返信文生成 |
