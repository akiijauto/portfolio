# 要件定義 — Project 32: Googleカレンダー連携 予定要約Bot

## 概要
Googleカレンダーを読み込んで今週の予定をGeminiが要約し、毎朝8時にDiscord・メールへ
自動送信するBot。Webダッシュボードで今週の予定一覧も確認できる。

## 機能要件
1. OAuth2でGoogleアカウント認証を行う（初回のみブラウザでの同意操作が必要）
2. 今週（今日から7日間）の予定をGoogle Calendar APIで取得する
3. Gemini APIが予定一覧を重要度順に並べ替えて日本語で要約する
4. 毎朝8時（JST）にAPSchedulerが自動実行し、要約をDiscord Webhook・メールへ送信する
5. 「今すぐ要約を送信する」ボタンで手動実行もできる
6. Webダッシュボードで今週の予定一覧とAI要約を表示する

## OAuth2の認証情報について
`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`はGoogle Cloud Consoleで取得する。
ブラウザでの同意画面操作（「許可」をクリックする部分）はユーザー本人のGoogle
アカウントでのログインが必要なため、自動化できない。取得したトークンは
`instance/google_token.json`にローカル保存し、以後はリフレッシュトークンで
自動更新する。

## データ構造
- `instance/google_token.json`: OAuth2のアクセストークン・リフレッシュトークン
  （`google.oauth2.credentials.Credentials.to_json()`形式）

## 画面構成
- `/` — 未連携時は「Googleでログイン」ボタン、連携済みなら今週の予定一覧・AI要約・
  手動送信ボタンを表示
- `/auth/login` — Google OAuth2同意画面へリダイレクト
- `/auth/callback` — OAuth2コールバック、トークンを保存
- `/run-now`（POST） — 要約生成・送信を即時実行する

## 技術スタック
Flask / google-api-python-client + google-auth + google-auth-oauthlib / APScheduler
（`BackgroundScheduler`、JST、毎朝8:00） / Discord Webhook + smtplib / Gemini API
（`shared.utils.call_claude_text`経由） / Render

## 成功条件
- 未連携時にダッシュボードを開くと「Googleでログイン」ボタンが表示される
- OAuth2の認可URLが正しいパラメータ（client_id・scope・redirect_uri）で生成される
  （実機で確認済み。実際の同意操作はユーザーが行う）
- 予定取得・AI要約に失敗した場合もダッシュボードの表示が落ちない
- Discord Webhook・SMTP情報が未設定の場合は、その送信先をスキップして処理を継続する
