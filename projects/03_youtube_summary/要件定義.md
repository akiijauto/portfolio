# 要件定義 — Project 03: YouTube要約ツール

## 概要

YouTube動画のURLを入力するだけで、Claudeが「動画要約」「主要ポイント5選」「SNS投稿用テキスト」を自動生成するツール。
URLが分からない場合は、キーワードから字幕付き動画を検索して選択し、そのまま要約できる。

## 機能要件

### ① URL要約
- YouTube URL（`watch?v=`/`youtu.be`/`shorts`/`embed`形式）を入力
- `youtube.fetch_video()` で動画タイトル・字幕テキストを取得
- 字幕が50文字未満の場合は `no_transcript` エラーを表示
- `summarizer.summarize()` でClaudeに動画要約・主要ポイント5選・SNS投稿用テキスト・カテゴリを生成させる
- 結果はカードごとにコピー可能、全体をテキストファイルでダウンロード可能

### ② キーワード検索→動画選択→要約
- キーワードを入力
- `youtube.search_videos()` でTavily Search API（`include_domains: youtube.com/youtu.be`）から候補URLを取得し、
  各候補について `YouTubeTranscriptApi.list()` で字幕の有無を軽量に確認、字幕が取得可能な動画のみ最大5件を返す
- `TAVILY_API_KEY` 未設定時は503エラーで「URLを直接入力してください」と案内
- 検索結果が0件の場合は「字幕付きの動画が見つかりませんでした」と表示
- 検索結果一覧から1件選択すると、そのURLが「①URL要約」の入力欄に入り、自動で要約が実行される

## データ構造・API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面 |
| `/search` | POST | キーワード検索（`keyword`） → `{ok, videos: [{video_id, title, url, thumbnail}]}` |
| `/summarize` | POST | URL要約（`url`） → `{ok, data: {video_id, title, summary, points, sns, category, transcript_len}}` |

## エラーハンドリング

- URL形式が認識できない → `ValueError` をそのままエラーメッセージとして表示
- 字幕が取得できない・短すぎる → `no_transcript`
- Claude要約失敗 → `handle_ai_error`（Anthropicクレジット残高不足時は `service_paused`）
- 検索API未設定 → 503、検索失敗 → `handle_ai_error`

## 技術スタック

- Flask + Flask-WTF（CSRF）
- youtube-transcript-api（字幕取得・字幕有無の確認）
- requests（oEmbedによる動画タイトル取得）
- Anthropic Claude API（claude-haiku-4-5）— `shared.call_claude_json`
- Tavily Search API（`TAVILY_API_KEY`、Project 02/13と共通パターン）

## 成功条件

1. URLを入力すると動画要約・主要ポイント5選・SNS投稿用テキストが生成される
2. キーワードを入力すると字幕付き動画の検索結果一覧が表示され、選択した動画がそのまま要約される
3. `TAVILY_API_KEY` 未設定でもURL要約機能は変わらず利用できる
4. ローカル起動 `python app.py` → ポート 5003 で動作
