# 振り返り — Project 03: YouTube要約ツール

## 発生した課題と解決策

### 1. キーワードからYouTube動画を直接検索する手段がない
**課題:** YouTube Data API（`search.list`）は専用のAPIキーが必要で、本プロジェクトでは未設定。
一方、字幕が取得できない動画を要約しようとすると `no_transcript` エラーになり、ユーザーが
URLを手探りで探す必要があった。

**解決策:** Project 02/13と同じTavily Search APIを`include_domains: ["youtube.com", "youtu.be"]`で
呼び出し、候補のYouTube動画URLを取得。各候補について`YouTubeTranscriptApi.list()`で字幕の有無を
軽量に確認（本文は取得しない）し、字幕が取得可能な動画のみ最大5件を検索結果として返す構成にした。

### 2. `os`モジュール未importでの実行時エラー
**課題:** `search_videos()`で`os.environ.get("TAVILY_API_KEY")`を使う実装にしたが、
`youtube.py`は元々`os`をimportしていなかったため`NameError`が発生した。

**解決策:** `youtube.py`先頭に`import os`を追加。既存ファイルへの機能追加時は、
新たに使うモジュールのimportが既存ファイルに含まれているか必ず確認するようにした。

### 3. 検索結果から要約までの導線
**課題:** 検索結果一覧を表示しても、そこから要約画面への導線が分かりにくいと
使い勝手が悪くなる。

**解決策:** Project 02の記事検索と同じパターンで、検索結果カードをクリックすると
自動的に「URLを入力」欄にURLがセットされ、`doSummarize()`が即時実行される設計にした。
