# 05_aliexpress_monitor 要件定義

## 概要
AliExpressなどECサイトの商品URLを登録し、毎朝9時に価格を自動チェックして値下がりをDiscordへ通知するボット。

## 機能要件
- 商品URLを登録すると初回価格を自動取得
- APSchedulerで毎日09:00 JSTに全商品の価格をチェック
- 値下がり時はDiscord Webhookで通知（金額・割合を含む）
- 手動チェック・手動価格入力・商品削除が可能
- 一括チェック（全商品を即時確認）

## データ構造（`data/products.json`）
```json
[
  {
    "id": "uuid",
    "url": "https://...",
    "name": "商品名",
    "initial_price": 1500,
    "current_price": 1200,
    "last_checked": "2026-06-16T09:00:00"
  }
]
```

## 画面構成
- `/` — 商品一覧・URL登録フォーム・最終チェック時刻

## 技術スタック
| 要素 | 内容 |
|------|------|
| フレームワーク | Flask |
| スクレイピング | requests + BeautifulSoup |
| スケジューラー | APScheduler（CronTrigger 09:00 JST） |
| 通知 | Discord Webhook |
| ストレージ | JSON ファイル |
| ポート | 5005 |

## 環境変数
| 変数名 | 用途 |
|--------|------|
| `DISCORD_WEBHOOK_URL` | 値下がり通知先 |

## 成功条件
- URLを登録すると価格が自動取得される
- 値下がりが発生するとDiscordに金額・割合付きで通知される
- 毎朝09:00に自動チェックが実行される
