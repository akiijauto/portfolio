# AliExpress価格監視ツール

商品ページのURLを登録するだけで価格を定期的に自動チェックし、値下がりを検知したらDiscordへ通知するツールです。
「毎日手動でサイトを確認する」手間をなくし、価格変動の見逃しを防ぐことを目的としています。

## 想定ユーザー

- 仕入れ商品の価格変動を継続的に追いたい個人事業主・せどり/転売事業者
- 複数の商品ページを毎日チェックするのが負担になっている方
- 値下がりタイミングを逃さず仕入れ判断をしたい方

## できること

1. **商品登録** — 商品ページのURLを登録すると、現在価格を自動取得して一覧に追加
2. **手動価格チェック** — 個別商品・全商品まとめての即時チェックが可能
3. **値下がり通知** — 前回価格より下がっていたら、下落額・下落率つきでDiscordへ通知
4. **商品の削除** — 監視対象から除外

※ 毎日9時の自動チェックは2026-07-30に停止済み（SNS投稿通知と同じDiscordチャンネルに
日次サマリーが混在するのを避けるため）。再開する場合は `app.py` の
`scheduler.add_job(daily_check, "cron", hour=9, minute=0)` を復活させてください。

対応サイト：AliExpress（専用パターンで価格抽出）／その他一般的なECサイト（汎用抽出ロジックでフォールバック）

## 使い方

1. トップ画面で商品ページのURLを入力して登録
2. 自動的に現在価格が取得され、一覧に表示される
3. 「チェック」ボタンで個別・一括チェックが可能。値下がりがあればDiscordに通知が届く

## ディレクトリ構成

```
05_aliexpress_monitor/
├── app.py            … Flaskアプリ本体（ルーティング・通知・スケジューラー）
├── scraper.py        … 価格スクレイピング（AliExpress専用＋汎用フォールバック）
├── storage.py        … 商品データ・価格履歴のJSON管理
├── data/
│   └── products.json … 登録商品データ（実行時に生成）
├── templates/
│   └── index.html
└── static/
    ├── app.js
    ├── base.css
    └── style.css
```

## セットアップ・起動

```bash
# リポジトリのルートで依存パッケージをインストール
pip install -r requirements.txt

# .env に DISCORD_WEBHOOK_URL を設定（通知を使う場合）

# このプロジェクトディレクトリで起動
cd projects/05_aliexpress_monitor
python app.py
```

ブラウザで http://127.0.0.1:5005 を開いて利用します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| バックエンド | Flask |
| スクレイピング | requests + BeautifulSoup |
| 定期実行 | なし（手動チェックのみ。自動チェックは2026-07-30に停止） |
| 通知 | Discord Webhook |
| データ保存 | JSONファイル（`data/products.json`） |

## 注意事項

- スクレイピングは対象サイトの利用規約・robots.txtの範囲内で行ってください
- サイト構造の変更により価格取得に失敗する場合があります（その際は `scraper.py` の抽出パターンを調整してください）
