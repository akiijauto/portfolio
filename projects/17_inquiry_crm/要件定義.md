# 要件定義 — Project 17: 問い合わせ管理CRM

## 概要

問い合わせ・案件情報を登録し、ステータス（新規〜成約/失注）の進捗管理を行うCRM。
Claude AIが問い合わせ内容に応じた返信メールの下書きも生成する。
Phase 3 Priority 5（クライアント基盤が増えてきた段階で活用する想定）として実装し、これでPhase 3の全5優先施策が完成。
他のProjectがステートレスなAI生成ツールであるのに対し、本プロジェクトはFlask-SQLAlchemy + SQLiteによる永続化データを持つ初のツール。

## 機能要件

### ① 新規登録
- 会社名・お名前（必須・100文字以内）、ご担当者名、メールアドレス、電話番号、流入経路（ホームページ/SNS/紹介/クラウドソーシング/その他）、問い合わせ内容（2000文字以内）を入力して案件を登録
- 登録時のステータスは自動的に「新規」

### ② 案件一覧・進捗管理
- ステータス（新規／連絡済み／商談中／成約／失注）でフィルタした案件一覧を表示
- 各案件のステータスをその場で変更可能
- 各案件にメモ（2000文字以内）を保存可能
- 案件の削除が可能
- 画面上部に「案件総数」「新規」「対応中（連絡済み・商談中）」「成約」の件数を表示

### ③ AI返信文生成
- 登録済み案件から1件選択し、返信トーン（丁寧（標準）／親しみやすい／簡潔）と「返信で伝えたいこと」（任意・200文字以内）を指定
- Claudeが問い合わせ内容に応じた返信メール文面（件名＋本文）を生成し、コピー可能

## データ構造・API

### Inquiryモデル（`inquiries`テーブル）

| カラム | 型 | 説明 |
| --- | --- | --- |
| id | Integer | 主キー |
| company | String(100) | 会社名・お名前（必須） |
| contact_name | String(100) | ご担当者名 |
| email | String(255) | メールアドレス |
| phone | String(50) | 電話番号 |
| source | String(50) | 流入経路 |
| content | Text | 問い合わせ内容 |
| status | String(20) | ステータス（新規/連絡済み/商談中/成約/失注） |
| memo | Text | メモ |
| created_at / updated_at | DateTime | 作成日時・更新日時 |

### API

| ルート | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | メイン画面（タブ切り替えUI） |
| `/api/stats` | GET | ステータス別件数・総数を取得 |
| `/api/inquiries` | GET | 案件一覧取得（`?status=`で絞り込み可） |
| `/api/inquiries` | POST | 案件を新規登録 |
| `/api/inquiries/<id>/status` | POST | ステータス更新 |
| `/api/inquiries/<id>/memo` | POST | メモ更新 |
| `/api/inquiries/<id>/delete` | POST | 案件削除 |
| `/reply_draft` | POST | AI返信文生成（`inquiry_id`, `tone`, `purpose`） |

## 画面構成（タブ）

1. **①新規登録** — 会社名/担当者/連絡先/流入経路（チップ選択）/問い合わせ内容の入力フォーム
2. **②案件一覧・進捗管理** — ステータスフィルタ + 案件カード一覧（ステータス変更・メモ・削除）
3. **③AI返信文生成** — 案件選択 + トーン選択（チップ）+ 伝えたいこと入力 → 返信文ドラフト表示・コピー

## 技術スタック

- Flask + Flask-WTF（CSRF）
- Flask-SQLAlchemy + SQLite（`sqlite:///inquiries.db`、`instance/`配下に自動作成）
- Anthropic Claude API（claude-haiku-4-5） — 返信文生成
- 共通: `shared/csrf_setup.py`, `shared/errors.py`, `static/base.css`

## 成功条件

1. 問い合わせ情報を登録すると、ステータス「新規」で一覧に表示される
2. ステータスフィルタ・ステータス変更・メモ保存・削除が正しく動作する
3. 案件を選択して返信文を生成すると、問い合わせ内容に応じたメール文面が生成される
4. ローカル起動 `python app.py` → ポート 5017 で動作（SQLiteデータは`instance/inquiries.db`に永続化）
