# 要件定義 — Project 35: CSVデータ 対話型分析ツール

## 概要
CSVをアップロードし、自然言語で「月別の売上合計は？」などと質問すると、Gemini AIが
質問を解釈してpandasで集計し、グラフ＋テキストで回答する対話型データ分析ツール。

## 機能要件
1. CSVファイルをアップロードする（10MBまで、拡張子`.csv`必須）
2. アップロード後、先頭5行のプレビューと`describe()`による統計サマリーを表示する
3. 自然言語で質問を入力すると、Gemini APIが「集計の軸列・対象列・集計方法・グラフ種別・
   一言回答」をJSON形式で返す
4. 返却されたJSONの列名はCSVの実列名と照合し、未知の列名や未対応の集計方法は拒否する
   （AIの出力をそのままコード実行しない安全設計）
5. 検証済みの集計方法のみpandasで実行し、matplotlibでグラフ化してブラウザに表示する
6. 「このデータで他に気になる点は？」ボタンでGeminiが統計サマリーから追加の気づきを提案する

## セキュリティ上の設計判断
Gemini APIに直接Pythonコードやpandasクエリ文字列を生成・実行させる方式は、
プロンプトインジェクション経由のコード実行リスクがあるため採用しなかった。
代わりに「集計の軸列・対象列・集計方法（sum/mean/max/min/count/medianのみ）・
グラフ種別（bar/lineのみ）」という限定されたJSONスキーマのみをAIに出力させ、
実際の列名・集計方法は事前定義したホワイトリストで検証してからpandasの
`DataFrame.groupby().agg()`に渡す。

## データ構造
DBは使用しない。アップロードされたCSVは`instance/csv_uploads/<uuid>.csv`に保存し、
Flaskセッション（signed cookie）にUUIDのみを保持する。

## 画面構成
- `/` — CSVアップロードフォーム、プレビュー、統計サマリー、質問フォーム、結果表示
- `/upload`（POST） — CSVアップロード
- `/ask`（POST） — 自然言語質問→AI解釈→集計→グラフ生成
- `/insight`（POST） — 統計サマリーからAIが追加インサイトを提案

## 技術スタック
Flask / pandas / matplotlib / Flask Session（signed cookie） / Gemini API
（`shared.utils.call_claude_json` / `call_claude_text`経由） / Render

## 成功条件
- CSV以外のファイルはアップロード時に拒否される
- AIが存在しない列名や未対応の集計方法を指定した場合、エラーメッセージを表示し落ちない
- 質問に対するグラフと一言回答が表示される
